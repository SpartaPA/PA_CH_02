# [65강. 로봇 탑재용 모델 배포 구조 (Jetson Orin/Thor)]
- 모듈: ⑨ 에지 컴퓨팅 및 실시간 배포
- 한 줄 요약: 로봇 몸속 AI 컴퓨터 **Jetson**의 구조와 **전력·열**이라는 새 물리 제약(피크 ≠ 지속 성능)을 이해하고, 모델을 컨테이너·버전·감시가 붙은 **배포 구조**의 부품으로 설계
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** Jetson 같은 에지 모듈의 구성과, 성능이 **전력 모드에 따라 달라짐**
- **필수 ②** **열 스로틀링** 때문에 피크 성능과 지속 성능이 다름을 설명
- **필수 ③** 모델 배포에 가중치 외에 **전처리·후처리·버전 정보**가 함께 가야 함을 설명
- 심화(선택): 방열 설계, 전력 예산 배분, 컨테이너 배포
- 원칙: **벤치마크는 열 평형 후에 잰다**

## [핵심 개념]
- **연산 3계층 중 Edge의 속** (Lv.1 1강: 임베디드–Edge–클라우드)
  - 모듈 ①이 임베디드(MCU)를 열었다면 이번엔 Edge — NVIDIA Jetson(Orin 세대, 휴머노이드용 차세대 Thor)
  - 데스크톱 GPU와의 차이는 성능 숫자보다 **제약의 종류**: 콘센트 → 배터리, 에어컨 → 좁은 몸통의 열
- **Jetson의 해부 — 한 모듈에 담긴 로봇의 뇌**
  - ARM CPU 코어
  - Ampere GPU + **Tensor Core** (64강 FP16/INT8의 하드웨어)
  - 전용 가속기: DLA(저전력 추론 오프로드), PVA(비전 전처리)
  - 비디오 인코더/디코더
  - **통합 메모리**: CPU·GPU가 같은 DRAM 공유 → 복사 없는 공유 가능 / 대역폭 경쟁도 함께
  - 모듈 ① MCU와 역할 분담: MCU = Hard 실시간, Jetson = AI 추론
- **라인업 감각 (전형 수치)**

  | 모듈 | 전력 | AI 성능 | 자리 |
  |---|---|---|---|
  | Orin Nano | 7~15 W | ~40 TOPS | 소형 로봇·교육 |
  | Orin NX | 10~25 W | ~100 TOPS | AMR·드론 |
  | AGX Orin | 15~60 W | ~275 TOPS | 자율주행·다센서 |
  | Thor (차세대) | 수십~백 W | ~2000 TFLOPS급 | 휴머노이드·트랜스포머 정책 |

  - **TOPS는 마케팅 숫자**: INT8 최대치, 실제는 메모리 대역폭·모델 구조가 좌우(63강) → "내 모델의 실측"만이 진짜 스펙(68강)
- **전력 모드 (nvpmodel)**
  - 15W/30W/MAXN 등 모드별 CPU/GPU 클럭 상한 변경 → **추론 지연 2~3배 차이**
  - 예: 같은 모델 15W 8.2 ms / 30W 4.5 ms / MAXN 3.1 ms
  - 63강 "측정 조건 명시"에 전력 모드가 들어가는 이유
- **열 스로틀링 — 지속 성능이라는 개념**
  - 계산 = 전력 = 열 → 좁은 몸통에 열이 갇히면 칩이 스스로 클럭 하향
  - MAXN 연속 부하 30분: 온도가 임계 도달 → 클럭 계단식 하강 → 지연 3.1 → 5.8 ms
  - **피크 성능 ≠ 지속 성능** → 벤치마크는 5분이 아니라 **열 평형 후** (69강 30분 소크 테스트)
  - 지표: 전력 모드 [W], 클럭 [GHz], 온도 [°C], 지연 [ms], 소크 시간 [min]
- **실무 함의 세 가지**
  - ① 방열 설계(팬·히트싱크)는 소프트웨어 성능의 일부
  - ② 마감 설계는 **스로틀링 상태의 지연** 기준(최악 기준 — 34강 P95 사상)
  - ③ 전력 예산은 로봇 전체(모터, 모듈 ①)와 공유 → 모터 피크와 추론 피크가 겹치면 전압 강하
- **배포 구조 — 스택의 자리**
  - [센서 드라이버] → [추론 노드(들): TRT 엔진 로드, 21·29강 구조] → [계획·제어(Nav2·정책 실행기)] → [micro-ROS/MCU(모듈 ①)] — ROS2 그래프로 연결
  - 옆에 배포 인프라 기둥: 컨테이너 런타임 / 모델 저장소 / 감시
  - 추론 노드는 보통 **여러 개**(검출·정책·깊이)가 GPU 공유 → 자원 경쟁 관리(69강)
- **포장·버전·감시 — 세 기둥** (61강 배포 체크리스트의 시스템 확장판)
  - **컨테이너(Docker)**: 보드 환경(CUDA·TRT·드라이버 버전)을 이미지로 고정 → 버전 지옥 봉인 (36강 "타인이 실행 가능한 저장소"의 산업판)
  - **모델 관리**: 엔진 파일에 버전·해시·출처(어느 학습·어느 캘리브레이션 데이터) 부착 → 롤백 가능해야 배포 (61강 stats 해시 검사의 확장)
  - **감시**: 추론 지연 P95·온도·전력·드롭률을 토픽으로 상시 발행 (35강 metrics_node의 시스템판) → "로봇이 굼떠요"에 그래프로 답
  - 배포 아티팩트 = 모델 + 전처리·후처리 + 설정 + 버전 (가중치 파일 하나로는 부족)
- **(심화) DLA와 이종 실행**
  - DLA: GPU보다 느리지만 전력 효율 좋은 전용 추론 엔진, 지원 연산 제한
  - 상시 보조 모델(저해상도 감시 검출 등)은 DLA, GPU는 주 정책에 비워 두는 **이종 배치**
  - TRT 빌드 시 DLA 타깃 지정, 미지원 층은 GPU 폴백 — 63강 EP 파티셔닝과 같은 문법
  - 전력 = 주행 시간인 로봇에서 "빠르게"만큼 "싸게"가 설계 목표

## [용어]
- **에지 컴퓨팅**: 로봇 위에서 직접 계산 — 지연·통신 의존 제거, 클라우드 추론과 대비
- **Jetson**: NVIDIA 로봇용 컴퓨팅 모듈 — 데스크톱 GPU와 성능·특성이 다름
- **전력 모드(nvpmodel)**: 소비 전력 상한 설정 — 같은 코드도 2~3배 차이
- **열 스로틀링**: 뜨거우면 스스로 느려짐 — 고장이 아닌 보호 동작
- **소크 테스트**: 오래 돌려 안정 상태 측정 — 짧은 벤치마크는 낙관적
- **배포 아티팩트**: 모델 + 전처리 + 설정 + 버전 — 재현 가능한 배포의 단위
- **전처리 일치**: 학습·배포 입력 처리 동일 — 리사이즈·정규화 차이가 정확도 붕괴의 흔한 원인
- **버전 고정**: 라이브러리·드라이버 버전 기록 — 엔진 재빌드·재현에 필수, 최신이 늘 좋은 것은 아님

- 64강: Tensor Core 위의 FP16/INT8, 엔진의 기종 종속 → [L64](../L64_TensorRT_변환과_FP16_INT8_양자화/)
- 66강: 스로틀링 상태 기준 마감·지연 예산 → [L66](../L66_실시간_배포_이슈와_지연_지표/)

- 69강: 다중 추론 노드 자원 경쟁, 엔진·노드·운영 문서 배포 패키지 → [L69](../L69_ROS2_제어_루프_통합_안정성_검증/)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **보드 정찰**: (Jetson 보유 시) `nvpmodel -q`·`tegrastats`로 전력 모드·클럭·온도 확인, 3개 모드에서 간단 추론 지연 비교 (미보유 시 제공 로그로 분석)
2. **전력 예산표**: TurtleBot3급 + Orin Nano 가정 — 모터 피크·컴퓨터·센서 소비와 배터리 용량으로 주행 시간 어림, 추론이 주행 시간에 주는 영향 계산
3. **배포 구조도**: 모듈 ⑩ 프로젝트 탑재 스택(어떤 추론 노드가 어떤 자원을 쓰는가)을 본문 형식으로 설계 + 감시 항목 목록
4. **(심화)** Dockerfile 골격: 추론 노드 하나를 컨테이너화(베이스 이미지 선택 근거 포함) → 69강에서 사용

## [확인 포인트]
- 데스크톱 GPU 대비 에지에서 새로 생기는 두 물리 제약과 소프트웨어적 함의는? (전력 → 모드·예산, 열 → 스로틀링·지속 성능 기준)
- 통합 메모리의 장점과 단점은? (복사 없는 공유 / CPU·GPU 대역폭 경쟁)
- "피크 ≠ 지속 성능"을 스로틀링으로 설명하고 벤치마크 절차의 함의는? (열 평형 후 측정, 소크 테스트)
- TOPS만으로 성능을 예측할 수 없는 이유는? (INT8 최대치, 실제는 대역폭·모델 구조가 좌우)
- 포장·버전·감시 세 기둥이 각각 막는 사고는? (환경 불일치, 롤백 불가·출처 불명, 성능 저하 미탐지)
