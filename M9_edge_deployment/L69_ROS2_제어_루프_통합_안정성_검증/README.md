# [69강. [실습] ROS2 제어 루프 통합·안정성 검증]
- 모듈: ⑨ 에지 컴퓨팅 및 실시간 배포
- 한 줄 요약: 워밍업·버퍼 사전 할당·최신 프레임 슬롯·deadline 미스 정책을 한 몸에 담은 TensorRT 추론 노드를 완성하고, 엔진·노드·성능 기록·운영 문서를 배포 패키지로 마감

## [핵심 개념]
- **추론 노드의 완성형**
  - 엔진 로드 + 워밍업 N회(63강)
  - 버퍼 사전 할당(66강) → 루프 중 메모리 할당 제거
  - 최신 슬롯 구독(29강): 큐에 쌓지 않고 가장 최근 프레임만 유지 → 오래된 프레임 처리 방지
- **데이터 나이(age)와 deadline**
  - $\text{age}=t_{now}-t_{stamp}$: 센서 캡처 시각부터의 경과 시간
  - 추론 시간만이 아닌 "결과가 얼마나 오래된 정보인가"로 판정
  - $\text{age}>\text{deadline}$이면 미스
- **미스 정책(66강 명세의 구현)**
  - 1회: 결과 버림
  - 연속 미스: 이전 결과로 외삽(예: 등속 가정 $\hat y_t=y_{t-1}+(y_{t-1}-y_{t-2})$)
  - 5연속: HOLD(안전 정지·유지) + 경고
  - 단계적 강등으로 제어 루프가 오래된 값에 반응하지 않게 함
- **진단 토픽**
  - `/inference/diag`: 지연 P50/P99, 드롭률, 온도 → 운영 중 상시 감시
  - 결과 메시지에 원 프레임 `header`를 그대로 실어 하류에서 시간 정렬 가능
- **엔진 무결성**
  - 엔진 경로 파라미터 + 결정서 해시 검증 → 검증된 엔진만 로드
- **배포 패키지**
  - 컨테이너(Dockerfile), 엔진, 노드·launch, 성능 기록, 운영 각본(RUNBOOK)을 한 트리로 관리
  - 롤백 절차까지 문서화

## [파일별 내용]
- `01_trt_inference_node_의사코드.txt` — 원본 `trt_inference_node.py` 구조
  - `__init__`: 엔진 로드·워밍업·버퍼 할당, 구독(최신 슬롯)·발행(결과 + `/inference/diag`), 파라미터(엔진 경로·미스 정책) — 주석만 존재
  - `on_timer()`: 타이머 콜백(고정 주기)
    - `t0 = stamp_of(frame)` → `self.engine.run(...)`(CUDA 이벤트 계측, 68강) → `age = now() - t0`
    - `age > self.deadline`: `miss_count` 증가 후 `apply_miss_policy()` 반환
    - 정상 시 `self.publish(out, header=frame.header)`
  - 빠진 맥락: `frame` 획득(최신 슬롯 읽기), 정상 시 `miss_count` 초기화, `apply_miss_policy` 구현, ROS 시간과 센서 시간 기준 통일
- `02_tree_deploy.txt` — `deploy/` 디렉터리 구조
  - `Dockerfile`(65강 실습 4 완성본), `engines/`(+결정서·해시, 67강), `nodes/`·`launch/`(이번 강의), `perf_sheets/`(68강), `RUNBOOK.md`(기동·감시 항목·미스/장애 각본·롤백)
