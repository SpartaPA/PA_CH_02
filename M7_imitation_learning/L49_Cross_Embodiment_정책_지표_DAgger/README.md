# [49강. Cross-Embodiment(Open X-Embodiment/RT-X)·정책 지표·DAgger]
- 모듈: ⑦ 로봇 모방학습 및 정책 최적화
- 한 줄 요약: "시연 데이터 부족을 어떻게 이기는가"라는 하나의 질문에 대한 세 답 — **남의 데이터 빌리기**(Cross-Embodiment), **정확히 재기**(성공률·jerk 지표), **필요한 라벨만 모으기**(DAgger·HG-DAgger)
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** Cross-Embodiment의 핵심 주장 — **여러 로봇 데이터를 합치면 각자보다 잘한다** — 과 그 전제(행동 공간 표준화)
- **필수 ②** 정책 평가에 **성공률만으로 부족한 이유**, 매끄러움 지표를 함께 봄
- **필수 ③** DAgger가 공변량 이동을 해결하는 방식 — **정책이 방문한 상태에 전문가 라벨을 붙인다**
- 심화(선택): OXE·RT-X 세부, 신뢰구간 계산, HG-DAgger 변형 — 지표 정의는 53강 평가기 구현으로 직결

## [핵심 개념]
- **Cross-Embodiment — 문제와 가설**
  - 시연 수집은 비쌈(로봇+사람+시간), 세계 연구실엔 몸(자유도·그리퍼·카메라)이 다른 로봇 데이터가 흩어져 있음
  - **Open X-Embodiment(OXE)**: 22개 기관·**22종 로봇·100만+ 에피소드**를 표준 형식(RLDS)으로 수집
  - **RT-X** 결과: 여러 로봇 데이터로 함께 학습한 정책이 각 로봇 자기 데이터만으로 학습한 정책보다 우수 (RT-1-X: 소규모 데이터 로봇들에서 평균 **~50% 향상**)
  - 이미지넷 사전학습처럼 "로봇 데이터의 총합"이 개별 로봇을 끌어올림 → **로봇 파운데이션 모델**의 근거
- **무엇이 전이되고, 조건은 무엇인가**
  - 공통 인터페이스로 정렬: 관측 = 카메라 이미지(몸 독립적), 행동 = **엔드이펙터 델타 + 그리퍼** (46강 심화의 선택이 결정적)
  - 전이되는 것: 시각 표현, 과제 구조, "잡으려면 다가가 연다" 같은 행동 문법
  - 전이 어려운 것: 몸 고유 동역학, 접촉 세부
  - **행동 공간 표준화가 전이의 관문** (관측 표준화보다 어려움)
- **실전 함의**
  - ① 데이터 형식을 표준(RLDS/LeRobot)으로 → 미래의 사전학습 자산 (46강 지침의 근거)
  - ② 사전학습 가중치에서 **미세조정**으로 시작이 소데이터 체제의 기본기 (25강 YOLO 미세조정과 같은 문법)
- **Success Rate — 왕이지만 비싸다**
  - 성공 조건 엄밀 정의(도달 반경·시간 한도·무충돌) → $N$회 롤아웃 성공 비율 + **신뢰구간**(45강 심화 Wilson)
  - 로봇 학습 논문의 1지표, 배치 격자별 **성공률 지도**가 더 정보적(어느 영역이 약한가)
  - 10회 중 80%와 100회 중 80%는 다른 근거
- **Trajectory Smoothness — 품질 지표**
  - 덜덜 떨며 성공하면 실물에선 실격(모터 마모·진동·소음·기어 충격·발열)
  - $\text{jerk RMS}=\sqrt{\mathbb E\big[\|\dddot q(t)\|^2\big]}$ — $q$ 관절각 [rad], $\dddot q$ 저크 [rad/s³]
  - 세 번 미분 = "명령이 얼마나 급격히 바뀌는가", 위치·속도가 비슷해도 매 스텝 튀면 큼
  - 15강 Quintic 궤적이 최소화하던 바로 그 값, 제곱이라 가끔 크게 튀는 것에 큰 벌점
  - 53강 평가기: 롤아웃 로그 행동 시퀀스를 세 번 차분해 계산
  - 보조 지표: 행동 변화량 $\sum\|a_{t+1}-a_t\|$, 경로 길이 비(45강 경로 효율의 조작판), 에피소드 시간
  - 대시보드 요지: 성공률이 같아도 smoothness가 다를 수 있음 → **지표 하나로는 정책을 다 말할 수 없음**
- **DAgger(Dataset Aggregation) — 공변량 이동의 정면 처방**
  1. 초기 시연으로 $\pi_0$ 학습 (= BC)
  2. $\pi_i$를 **실행**해 상태를 방문하고, 그 상태에서 **전문가가 정답 행동 라벨링**
  3. 새 $(o,a^*)$를 데이터셋에 **합쳐** 재학습 → 반복
  - 데이터 분포가 회를 거듭할수록 **정책의 방문 분포**를 덮음
  - 이론 보증: 복합 오차 $O(\epsilon T^2)\to O(\epsilon T)$ (47강 정리의 후속)
  - 같은 총 데이터량의 BC 대비 성공률 곡선이 가파르게 상승 — "어디서 배울지를 정책의 실패가 알려 준다"(능동 학습)
- **원조 DAgger의 현실 문제**
  - 라벨링 고역: 실행 중 매 스텝 전문가가 (실행되지 않는) 정답 입력
  - 위험: 서툰 정책이 실물을 부수러 갈 때도 구경만
- **HG-DAgger(Human-Gated)**
  - 평소엔 정책이 운전, 전문가는 감독 → 위험/이탈 순간에만 **개입해 넘겨받고** 개입 구간 $(o,a^*)$만 추가
  - 라벨이 정책이 약한 곳에 집중, 안전 확보(사람이 게이트) + 라벨 비용 급감
  - 보너스 지표: **개입률**(시간당 개입 횟수) = 정책 성숙도 지표 (54강 학습 곡선)
- **(심화) 개입 데이터의 편향과 절충**
  - 개입 구간만 모으면 "위기 탈출" 행동에 편중, 정상 유지 행동 희석
  - 개입 시점이 전문가마다 달라 게이트 기준의 일관성 = 데이터 품질
  - 절충 예: 개입 구간 + **직전 2초** 저장, 개입 기준 문서화(이탈 거리·위험 근접), 라운드마다 정상 시연 소량 추가
  - 자율주행 업계의 "마일당 인간 개입 횟수" = HG-DAgger 사상의 산업판

## [용어]
- **Cross-Embodiment**: 서로 다른 몸(로봇) 사이의 학습 전이 — 같은 로봇의 데이터 증강과 다름
- **행동 공간 표준화**: 로봇마다 다른 명령을 공통 형식으로 — 관측 표준화보다 어려운 전이의 관문
- **파운데이션 모델**: 대규모 사전학습 모델, 미세조정의 출발점 — 완성품이 아니라 기반
- **성공률(Success Rate)**: 목표 달성 비율 — 조건 정의와 시행 수에 크게 좌우
- **신뢰구간**: 측정값의 불확실 범위 — 적은 시행에서의 과신 방지
- **저크(jerk)**: 명령이 급격히 바뀌는 정도(가속도의 미분) — 속도·가속도와 다른 차수
- **DAgger**: 정책이 간 자리에 전문가 라벨 붙이기 — 데이터를 무작정 늘리는 것과 다름
- **HG-DAgger**: 위험할 때만 사람이 개입 — 전 구간 라벨링과 대비
- **라벨 효율**: 적은 라벨로 큰 성능 향상 — 데이터 총량과 다른 관점

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **OXE 답사**: 데이터셋 목록에서 서로 다른 로봇 3종 → 관측·행동 공간이 표준 형식에 담긴 방식 표
2. **지표 구현 예열**: 15강 Quintic 궤적과 노이즈 낀 지그재그 궤적에 jerk RMS·행동 변화량 함수 적용, 값 차이 확인 (53강 핵심 함수)
3. **DAgger 종이 시뮬레이션**: 47강 1차원 장난감에서 라운드마다 "롤아웃 상태 10개에 전문가 라벨 추가" 3회 반복 → 롤아웃 발산이 잡히는 과정 그리기
4. **(심화) 개입률 지표 설계**: 54강용 "개입 시작/종료" 이벤트 기록 방식과 개입률·개입당 평균 길이 정의 문서화

## [확인 포인트]
- OXE/RT-X의 핵심 결과를 한 문장으로, 그리고 데이터 형식을 표준으로 맞추는 이유는? (합친 데이터가 개별보다 우수 / 미래 사전학습 자산)
- 행동 공간을 엔드이펙터 델타로 표준화하는 것이 왜 전이의 관문인가? (관절 명령은 몸에 종속)
- 성공률이 같은 두 정책을 가르는 지표 두 가지와 각각 잡아내는 결함은? (jerk RMS = 떨림, 행동 변화량·경로 길이 비 = 급변·우회)
- DAgger가 $O(\epsilon T^2)$를 $O(\epsilon T)$로 만드는 원리를 "방문 분포"로 설명할 수 있는가?
- HG-DAgger가 해결하는 원조 DAgger의 두 문제와 그 대가인 데이터 편향은? (라벨 부담·안전 / 위기 탈출 행동 편중)
