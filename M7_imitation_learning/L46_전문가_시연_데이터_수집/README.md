# [46강. 전문가 시연 데이터 수집 (Teleoperation·Kinesthetic Teaching)]
- 모듈: ⑦ 로봇 모방학습 및 정책 최적화
- 한 줄 요약: 규칙으로 적을 수 없는 과제를 위해 **시연 $\{(o_t,a_t)\}$에서 정책 $\pi(a\mid o)$를 배우는** 모방학습의 출발점 — 수집 방식(원격 조종·직접 교시)과 좋은 시연 데이터의 조건
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** "정책을 배운다" = **관측 → 행동 함수 학습**임을 설명
- **필수 ②** 원격 조종과 직접 교시의 **차이와 장단점**
- **필수 ③** 좋은 시연 데이터의 조건(일관성·다양성·복구 포함·동기화)
- 심화(선택): 데이터 규모와 성능의 관계, 수집 장비 구성 — "복구 장면 포함" 원칙의 이유는 47강 공변량 이동에서 밝혀짐

## [핵심 개념]
- **왜 모방학습인가**
  - 지금까지의 행동은 전부 사람이 쓴 규칙(PID 게인, HSV 범위, costmap 가중치)
  - "구겨진 수건 개기", "봉지에서 과자 꺼내기" → 상태는 무한, 접촉 물리는 모델링 거부 → 규칙 작성 불가
  - 25강이 "검출 규칙을 데이터에서 학습"이었다면, 이번엔 **행동 자체를 데이터에서 학습** (RT-X, ALOHA, Diffusion Policy 모두 이 틀)
  - 학습(47강 이후)의 성패는 대부분 **데이터 단계에서 결정**
- **문제 설정**
  - 정책: 관측 $o_t$(카메라·관절 상태) → 행동 $a_t$(관절 명령·엔드이펙터 속도)인 함수 $\pi(a_t\mid o_t)$
  - 모방학습: 전문가 시연 궤적 $\{(o_t,a_t)\}$을 모아 그 매핑을 흉내 내는 $\pi$ 학습
  - 기존 스택(인지→계획→제어 파이프라인) vs 정책 하나가 관측→행동 직결(end-to-end 또는 부분 대체)
  - **대체가 아니라 분업**: 구조적·검증 필요 과제(주행, 조립)는 규칙, 비정형 접촉 과제(천·음식·잡동사니)는 학습 — Nav2를 버리는 게 아님
- **RL과의 차이**
  - RL: 보상 설계 + 시행착오(수백만 번 실패 — 실물에선 위험·고비용)
  - 모방학습: 정답 행동을 직접 보고 학습, 수십~수백 시연이면 시작 → **표본 효율** 덕에 실물에서 먼저 쓰임
- **수집 방식 ① Teleoperation(원격 조종)**
  - 사람이 조종 장치로 로봇을 움직이며 (관측, 행동) 기록
  - 인터페이스 스펙트럼: 게임패드/스페이스마우스(저가, 자유도 매핑 부자연) → **리더-팔로워 팔**(작은 복제 팔을 움직이면 실제 팔 추종, ALOHA 방식, 자연스럽고 정밀) → VR 컨트롤러(6DOF 직관)
  - 결정적 장점: **관측과 행동이 로봇의 것** → 학습 정책의 입출력과 같은 분포
  - 단점: 조종 숙련 필요(시연 품질 = 조종 실력), 지연·어색한 자유도 매핑이면 시연이 서툴러짐
- **수집 방식 ② Kinesthetic Teaching(직접 교시)**
  - 로봇 팔을 손으로 잡고 움직임 — 12강 **중력 보상 모드** $\tau=\hat g(\theta)$가 이를 위한 기능
  - 장점: 직관적, 조종 장치 학습 불필요, 접촉 힘을 사람이 직접 조절 → 협동로봇 현장 교시의 표준
  - 단점: **관측 오염** — 카메라에 사람 팔이 찍힘 → "사람 손이 보이면 움직인다" 같은 엉뚱한 상관 학습 위험(학습/실행 분포 차이), 사람이 옆에 있어야 해 원격·위험 환경 불가
- **방식 비교 요약**

  | 축 | Teleoperation | Kinesthetic |
  |---|---|---|
  | 자연스러움 | 장치·숙련에 좌우 | 높음(직관적) |
  | 관측 정합 | 우수(실행 때와 같은 관측) | 사람 손 오염 |
  | 원격 가능 | 가능 | 불가 |
  | 장비 비용 | 장치에 따라 다름 | 중력 보상 기능 필요 |

  - 학습용 기준은 **"실행 때와 같은 관측"** → Teleoperation 선호
- **좋은 시연 ① 관측-행동 시간 정합**
  - $o_t$와 $a_t$는 **같은 순간**의 짝이어야 함
  - 카메라 30 Hz, 관절 상태 100 Hz, 조종 명령 50 Hz 등 주기가 다른 스트림 → 21강 `header.stamp`로 묶기(50강 실습 주제)
  - 어긋난 짝 = "보기 전에 행동하는" **인과 붕괴** 데이터
- **좋은 시연 ② 다양성 — 분포를 덮어라**
  - 정책은 본 것만 앎: 물체를 왼쪽에만 두고 시연하면 오른쪽 물체 앞에서 임의 행동
  - 수집 프로토콜: 물체 위치·자세를 격자/무작위로 변경(25강 조건 다양화, 모듈 ⑧ 도메인 랜덤화 예고), **실패-복구 장면도 일부러 포함**(53강에서 가치 확인)
- **좋은 시연 ③ 일관성 — 갈림길의 저주(48강 복선)**
  - 같은 상황에서 좌/우 회피 등 전략이 섞이면 평균을 배우는 학습기는 **가운데(충돌)**로 감
  - 다중 모드(multimodal) 행동 분포 문제 = 47강 BC의 한계, 48강 Diffusion Policy의 존재 이유
  - 당장의 지침: 한 데이터셋 안에서 전략 통일, 또는 다중 전략임을 알고 수집
- **데이터셋 형식 — 표준을 따르라**
  - 에피소드 단위, 스텝마다 (obs: 이미지·상태, action, 시각)
  - 실습: HDF5(robomimic 호환 구조), 커뮤니티 표준: **LeRobot 형식**, RLDS(Open X-Embodiment, 49강)
  - 표준 형식 = 남의 도구·데이터와 호환 (vision_msgs를 쓴 것과 같은 이유)
- **(심화) action space 선택**
  - 관절 각도 목표(절대) / 관절 속도(상대) / 엔드이펙터 포즈(작업 공간) / 엔드이펙터 델타
  - 절대 목표: 누적 오차 없음, 그러나 로봇 몸에 종속(49강 cross-embodiment의 장벽)
  - 델타: 몸 독립적, 그러나 드리프트 누적(14강 속도 IK 드리프트와 같은 병)
  - 작업 공간 행동은 실행기에 IK(10강) 필요
  - 최근 표준: **엔드이펙터 델타 + 그리퍼 개폐**, 51강에서 관절/작업 공간 비교

## [용어]
- **정책(policy)**: 관측을 받아 행동을 내는 함수 — 궤적과 다름, 상황마다 행동을 냄
- **관측(observation)**: 로봇이 보는 입력 — 상태(state)의 일부만 보일 수 있음
- **행동(action)**: 정책이 내는 명령 — 정의 방식에 따라 학습 난이도가 크게 달라짐
- **시연(demonstration)**: 전문가의 (관측, 행동) 기록 — 영상과 달리 행동 라벨이 함께 있어야 함
- **원격 조종(teleoperation)**: 조작기로 수집, 행동이 그대로 라벨 — 조작 장치가 품질 좌우
- **직접 교시(kinesthetic)**: 손으로 끌어 가르치기 — 중력 보상(12강) 전제
- **에피소드**: 시연 1회(시작~끝), 데이터 기본 단위 — 프레임 하나와 구분
- **동기화(sync)**: 관측·행동 시각 맞추기 — 어긋나면 학습 전체가 망가짐, 50강 핵심
- **복구 시연**: 일부러 벗어났다 돌아오는 장면 — 완벽한 시연만 모으면 오히려 취약

## [선수 지식·연결]
- 12강: 중력 보상 모드, 10·14강: IK와 속도 IK 드리프트, 21강: `header.stamp`, 25강: 데이터 기반 학습·조건 다양화

- 48강: 갈림길의 저주와 Diffusion Policy → [L48](../L48_Diffusion_Policy_행동_분포_모델링/), 49강: RLDS·cross-embodiment → [L49](../L49_Cross_Embodiment_정책_지표_DAgger/)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **과제 분류**: (가) 창고 팔레트 주행 (나) 세탁물 분류 (다) 나사 조립 (라) 샐러드 담기 (마) 문 열기 → 규칙/모방학습/혼합 분류와 근거
2. **수집 계획서**: 51강 "2링크 팔로 물체 도달" 과제 — 관측·행동 정의, 방식(마우스 teleop), 배치 다양화 격자(최소 5×5), 에피소드 수, 실패-복구 포함 여부
3. **정합 사고 실험**: 카메라가 100 ms 지연된 기록계로 빠른 스윙을 시연할 때 $(o,a)$ 짝의 왜곡을 타임라인으로 설명 (50강 예습)
4. **(심화)** LeRobot 허브 공개 데이터셋 하나 조사 — 에피소드 수·관측 구성·행동 공간·수집 방식 표

## [확인 포인트]
- 2링크 팔 시스템에서 정책 $\pi(a\mid o)$의 입력·출력을 구체적 신호로 들 수 있는가? (관절각·물체 위치 → 관절 명령)
- 수건 개기 같은 접촉 과제에서 규칙 기반이 어려운 이유 두 가지는? (무한한 상태, 모델링 불가한 접촉 물리)
- Kinesthetic Teaching의 관측 오염이 만드는 엉뚱한 행동의 예는? (손이 보일 때만 움직이는 정책)
- 물체를 항상 같은 위치에 두고 모은 시연 100개의 문제와 처방은? (분포 미커버 → 배치 격자 다양화)
- 좌/우 회피가 반반 섞인 데이터에서 평균을 배우는 정책이 위험한 이유는? (평균 = 정면 충돌)
