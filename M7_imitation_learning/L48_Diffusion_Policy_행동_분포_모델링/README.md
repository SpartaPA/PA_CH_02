# [48강. Diffusion Policy 행동 분포 모델링]
- 모듈: ⑦ 로봇 모방학습 및 정책 최적화
- 한 줄 요약: 정답이 여럿인 갈림길에서 MSE BC가 **평균(정면 충돌)**을 내는 이유를 이해하고, 행동을 "예측"이 아니라 **"생성"**하는 확산 모델과 Diffusion Policy(관측 조건부·행동 청크·리시딩 호라이즌)의 원리를 직관으로 잡기
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** 정답이 여러 개인 상황에서 **MSE 평균이 왜 실패하는지** 설명
- **필수 ②** 확산 모델 아이디어 — **노이즈를 걷어 내며 샘플을 만든다** — 를 말로 설명
- **필수 ③** Diffusion Policy가 **다중 모드를 표현**할 수 있는 이유
- 심화(선택): 노이즈 스케줄, 샘플링 스텝 수와 추론 비용, 구현 세부 — 수식 유도는 심화, 52강 코드로 감각 잡기

## [핵심 개념]
- **문제의 뿌리 — 평균은 정답이 아니다**
  - $\min_\theta\mathbb E\|\pi_\theta(o)-a\|^2\ \Rightarrow\ \pi_\theta(o)=\mathbb E[a\mid o]$ (MSE 최적해 = **조건부 평균**)
  - 시연이 좌/우 반반 → 평균 = 가운데 = 장애물 정면, 두 정답 중 어느 것도 아님
  - 이봉 분포에서 MSE 출력은 두 봉우리 사이 **골짜기(확률 최저)**에 위치 — "둘 다 배우려다 아무것도 아닌 것을 배움"
  - **데이터를 늘려도 해결 안 됨** — 데이터가 아니라 목적함수·모델 표현력의 문제 ($\pi_\theta(o)$가 행동 하나만 출력하는 함수인 한 두 정답을 못 담음)
  - 고전 처방: 가우시안 혼합(GMM) 머리, 행동 이산화 → 고차원·연속 행동에서 가장 강력한 답은 생성 모델(확산)
- **처방의 발상 전환**
  - 정답 **분포 자체**를 배워 실행 때마다 샘플 → 매번 좌 또는 우 하나를 고르되 가운데는 없게
  - 이미지 생성(Stable Diffusion)을 로봇 행동에 이식한 Diffusion Policy(2023), 조작 벤치마크 최강 계열
- **확산 모델 — 두 과정의 쌍**
  - 정과정(고정, 학습 없음): 진짜 데이터에 노이즈를 조금씩 더해 $K$ 스텝 만에 순수 노이즈로
  - 역과정(학습 대상): 각 스텝에서 "지금 낀 노이즈"를 맞히는 신경망 $\epsilon_\theta$ → 순수 노이즈에서 한 스텝씩 걷어 내며 데이터 생성
  - 학습 목표: $\min_\theta\mathbb E_{a,\epsilon,k}\big\|\epsilon_\theta(a+\sigma_k\epsilon,\ k,\ o)-\epsilon\big\|^2$
    - $a$ 참 행동, $\epsilon$ 무작위 노이즈, $\sigma_k$ $k$단계 노이즈 크기, $o$ 관측(조건)
    - (52강 구현의 DDPM 닫힌 식: $a_k=\sqrt{\bar\alpha_k}\,a_0+\sqrt{1-\bar\alpha_k}\,\epsilon$)
- **왜 손실이 MSE인데 평균 붕괴가 없나**
  - 맞히는 대상이 **행동이 아니라 노이즈**
  - 추론: 무작위 노이즈에서 출발 → 시작 노이즈가 다르면 걷어 내기 경로가 달라져 **다른 봉우리에 도착**
  - 다중 모드가 **샘플링의 무작위성**으로 자연스럽게 표현 — "평균으로 뭉개지 않고 매번 한 봉우리를 고른다"
- **Diffusion Policy — 이식의 세 가지 설계**
  - ① **관측 조건부 생성**: 생성 대상은 이미지가 아니라 행동, 조건은 프롬프트가 아니라 관측(이미지 인코딩+상태) → $\epsilon_\theta(a^k,k,o)$, 47강 정책 인코더가 조건 입력
  - ② **행동 시퀀스(청크) 생성**: 미래 $H$스텝(예: 16)을 한 번에 생성 (47강 처방 3의 실현)
    - 다중 모드가 **시퀀스 수준**에서 유지 — "왼쪽 계획 전체" vs "오른쪽 계획 전체", 스텝별 좌우 섞임(지그재그) 방지
    - 오차 누적 주기가 $1/H$로 → 공변량 이동(47강) 크게 완화
  - ③ **리시딩 호라이즌 실행**: $H$스텝 생성 후 **앞 $h$스텝만 실행**, 새 관측으로 재생성
    - 40강 Nav2 주기 재계획과 같은 사상(MPC 스타일) — **계획 일관성 ↔ 반응성**의 절충
  - 전체 흐름: 관측 인코딩 → 조건 주입 → 노이즈 시퀀스에서 $K$회 디노이징 → 행동 시퀀스 $H$스텝 → 앞 $h$스텝 실행 → 반복
- **비용과 선택 기준**

  | 항목 | Diffusion Policy | BC(47강) |
  |---|---|---|
  | 다중 모드 | 표현 가능 | 평균 붕괴 |
  | 추론 비용 | 디노이징 $K$회(수십 배) — 모듈 ⑨의 고객 | 순전파 1회 |
  | 데이터 요구 | 다소 많음 | 적음 |
  | 적합 과제 | 갈림길·접촉·비정형 조작 | 전략이 단일한 과제 |

  - BC가 틀린 도구는 아님 — 전략이 단일하면 싸고 충분, 핵심 질문은 "내 시연 분포가 다중 모드인가" (53강 판별 실험)
- **(심화) 같은 문제의 다른 답**
  - **ACT**(Action Chunking with Transformers, ALOHA 정책): CVAE+Transformer로 시퀀스 생성, 1회 순전파로 빠름, 다중 모드 표현력은 확산보다 제한적
  - **흐름 매칭(flow matching)·일관성 모델**: 디노이징 스텝을 크게 줄여 추론 비용 공략 (π0 등 최신 로봇 파운데이션 모델)
  - 지도의 두 축: **분포 표현력 ↔ 추론 속도** — 52강은 표준 DDPM 계열

## [용어]
- **다중 모드(multi-modal)**: 정답이 여러 개인 상황, 조작에서 흔함 — 노이즈가 많은 것과 다름(봉우리가 여럿)
- **평균 붕괴(mode averaging)**: 여러 정답의 평균을 내 버림 — 학습 부족이 아니라 목적함수의 성질
- **확산 모델(diffusion)**: 노이즈를 걷어 내며 샘플 생성 — GAN·VAE와 다른 생성 방식
- **노이즈 예측**: 섞인 노이즈를 알아맞히기 — 행동을 직접 예측하는 것과 결정적 차이
- **샘플링 스텝**: 노이즈를 걷어 내는 반복 횟수, 품질↔속도 — 학습 스텝(epoch)과 다름
- **조건부 생성**: 관측을 조건으로 행동 생성 — 정책으로 쓰기 위한 형태
- **액션 청킹**: 여러 스텝 행동을 한 번에 출력 — 추론 횟수 절감·일관성 향상
- **추론 비용**: 행동 한 번 내는 데 드는 계산 — 학습 비용과 별개, 실시간 제어의 제약(모듈 ⑨)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **평균 붕괴 재현**: 관측 없이 행동이 $\{-1,+1\}$ 반반인 데이터로 MSE 회귀 → 출력 0 확인, GMM(2성분) 머리로 바꿔 두 봉우리 포착 비교
2. **미니 확산 1차원**: 이봉 데이터에 노이즈 예측 MLP(입력: 노이즈 낀 값 + 스텝 $k$) 학습 → 샘플 50개 디노이징 후 히스토그램이 이봉을 재현하는지 확인 (52강 핵심 루프의 최소판)
3. **시작점 추적**: 시작 노이즈 5개의 디노이징 경로를 스텝별로 그려 어느 봉우리로 흐르는지 관찰
4. **(심화)** 디노이징 스텝 $K$를 50/10/4로 줄이며 이봉 재현도와 시간 측정 — 표현력↔추론 속도 축 직접 만들기 (모듈 ⑨ 예고)

## [확인 포인트]
- MSE 최적해가 조건부 평균이라는 사실이 이봉 행동 분포에서 왜 치명적인가? (평균 = 골짜기 = 충돌 경로)
- 확산 학습도 MSE인데 평균 붕괴가 없는 이유를 "맞히는 대상"으로 설명할 수 있는가? (행동이 아닌 노이즈)
- 행동을 시퀀스(청크)로 생성하면 좋은 점 두 가지는? (시퀀스 수준 모드 유지, 오차 누적 완화)
- 리시딩 호라이즌은 Nav2의 어떤 동작과 같은 사상이며 무엇과 무엇의 절충인가? (주기 재계획, 일관성↔반응성)
- 참/거짓: Diffusion Policy는 항상 BC보다 우월하므로 모든 과제에서 대체해야 한다 (거짓 — 단일 전략이면 BC가 싸고 충분)
