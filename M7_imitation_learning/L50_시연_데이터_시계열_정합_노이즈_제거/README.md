# [50강. [실습] 시연 데이터 시계열 정합·노이즈 제거]
- 모듈: ⑦ 로봇 모방학습 및 정책 최적화
- 한 줄 요약: 마우스로 시연을 모으고, 주기가 다른 센서·명령 스트림을 하나의 시간 격자 위 $(o,a)$ 쌍으로 정합해 정제된 HDF5 데이터셋과 품질 리포트를 만드는 실습

## [핵심 개념]
- **다주기 스트림 문제** → 관절 상태·물체 위치·명령이 서로 다른 주기·타임스탬프로 기록 → 그대로는 같은 시점의 $(o,a)$ 짝이 없음
- **공통 시간 격자** → $t_k=t_0+k/\text{hz}$ (여기서 20 Hz)에 모든 스트림을 재표본화
- **선형 보간(연속량)** → $x(t)=x_i+\frac{t-t_i}{t_{i+1}-t_i}(x_{i+1}-x_i)$
  - 관절각·관절속도처럼 물리적으로 연속인 값에 사용
- **최근값 유지(zero-order hold)** → $x(t)=x_i,\ t_i\le t<t_{i+1}$
  - 저주기 관측(물체 위치), 명령(행동)에 사용
  - 명령을 보간하면 실제로 내린 적 없는 중간 명령이 생김 → "보간 금지"
- **미래 정보 누설 주의** → 보간은 $t_{i+1}$(미래 샘플)을 쓰므로 실시간 정책 입력과 미묘한 차이 발생, hold는 과거만 사용
- **노이즈 제거** → 손떨림 등 고주파 성분을 필터로 줄이되 지연·형상 왜곡과의 상충 고려
- **데이터 누설 방지** → 정규화 통계(평균·표준편차)는 train 분할에서만 계산해 저장
- **에피소드 메타데이터** → 성공 여부·복구 시연 여부·시드 → 필터링·분석 기준

## [파일별 내용]
- `01_collector.ipynb` — `collector.py` 사용법(주석만)
  - `--episodes 60 --seed 7`
  - 물체 위치: 5×5 격자 + 지터(46강 다양성 프로토콜)
  - `r` 키 = 에피소드 폐기, 스페이스 = 성공 마킹
- `02_align.ipynb` — `align.py`의 `align_episode(state, action, scene, hz=20)`
  - `t_grid = np.arange(t0, t1, 1/hz)`: 공통 격자(`t0`, `t1` 계산부는 생략됨 — 모든 스트림이 겹치는 구간이어야 함)
  - `interp_linear`: `theta`, `dtheta` 선형 보간
  - `hold_last`: `scene.obj`(물체), `action.cmd`(명령) 최근값 유지
  - 반환: 관측 `column_stack([th, thd, obj])` → $(N,6)$, 행동 `act` → $(N,2)$
  - 빠진 맥락: `interp_linear`/`hold_last` 구현(`np.interp`, `np.searchsorted` 등으로 구현 가능), 노이즈 필터 단계
- `03_산출물_HDF5와_품질_리포트.txt` — `demos_clean.hdf5` 구조
  - `data/ep_000/`: `obs(N,6)`, `actions(N,2)`, `timestamps(N)`
  - 에피소드 attrs: `success`, `recovery`, `seed`, `collector`
  - 루트 attrs: `hz: 20`, `obs_spec`, `act_spec`, `norm_stats`(train만), `version`
