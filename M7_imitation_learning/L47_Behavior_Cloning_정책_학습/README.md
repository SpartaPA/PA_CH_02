# [47강. Behavior Cloning 정책 학습]
- 모듈: ⑦ 로봇 모방학습 및 정책 최적화
- 한 줄 요약: 전문가 시연 $(o,a)$ 쌍을 지도학습으로 흉내 내는 Behavior Cloning(BC)의 원리를 이해하고, 51강 실습 무대인 2링크 도달 과제의 최소 정책 구조를 미리 봄

## [핵심 개념]
- **모방학습의 설정** → 보상 함수 대신 전문가 시연 $\mathcal D=\{(o_i,a_i)\}$ 사용
- **Behavior Cloning** → 관측 → 행동 회귀 문제
  - 목적: $\min_\theta\ \mathbb E_{(o,a)\sim\mathcal D}\,\|\pi_\theta(o)-a\|^2$ (연속 행동에서 MSE)
  - 가우시안 우도 최대화와 같은 식 → 행동 분포가 단봉이라는 가정이 숨어 있음(다봉 문제는 48·52강)
- **관측 설계** → 정책이 행동을 결정하는 데 필요한 정보만, 실물에서도 얻을 수 있는 값으로
  - 2링크 과제: 관절각 $\theta_{1,2}$, 관절속도 $\dot\theta_{1,2}$, 물체 위치 $(x,y)$ → 6차원(50강 HDF5 `obs(N,6)`과 일치)
- **행동 설계** → 2차원 관절 명령(`actions(N,2)`)
- **MLP 정책** → 저차원 관측에는 은닉층 2개의 작은 MLP로 충분
- **BC의 한계(49강 예고)** → 학습 분포 밖 상태에서 오차가 누적되는 공변량 이동, 대략 $O(T^2)$ → 54강 DAgger
- **정규화** → 관측·행동 스케일 차이가 크면 학습 불안정, 통계는 학습 분할에서만 계산(50강)
