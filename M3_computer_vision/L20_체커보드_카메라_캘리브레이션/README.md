# [20강. [실습] 체커보드 카메라 캘리브레이션 (intrinsic/distortion)]
- 모듈: ③ 컴퓨터 비전 + 카메라 모델
- 한 줄 요약: 체커보드 사진 여러 장으로 내부파라미터 $K$와 왜곡계수를 추정하고, 재투영 오차와 undistort 결과로 품질을 판정한 뒤 파일로 저장해 재사용하는 실습

## [핵심 개념]
- **Zhang 방법**
  - 크기를 아는 평면 패턴(체커보드)을 여러 자세로 촬영
  - 보드 좌표계에서 코너는 $Z=0$ 평면 위 → 장마다 평면-이미지 호모그래피 하나
  - 여러 장의 호모그래피에서 $K$를 닫힌 해로 구하고, 왜곡까지 포함해 비선형 최적화로 정밀화
- **3D 기준점 `objp`**
  - $(i\cdot SQ,\;j\cdot SQ,\;0)$ 격자, $SQ$ = 한 칸 실측 길이
  - $SQ$는 $K$와 왜곡에는 영향이 거의 없고 외부파라미터 `tvecs`의 **단위·스케일**을 결정
- **내부 코너 수**: `(9, 6)`은 칸 수가 아니라 칸이 만나는 내부 교차점 수(칸은 10×7)
- **서브픽셀 코너 정밀화**
  - `cornerSubPix`: 코너 주변 그라디언트로 위치를 픽셀 이하 정밀도로 보정
  - 종료 조건: 최대 30회 반복 또는 이동량 $10^{-3}$ px 미만
- **재투영 오차 RMS**
  - 추정한 $K$, 왜곡, 각 장의 $R,t$로 `objp`를 다시 투영해 검출 코너와 비교한 픽셀 오차의 RMS
  - $\text{RMS}=\sqrt{\frac{1}{N}\sum_i\|p_i-\hat p_i\|^2}$ → 캘리브레이션의 "성적표"
  - 일반적으로 1 px 미만이면 양호한 편, 크게 높으면 흐린 사진·코너 오검출·보드 휨 의심
- **촬영 다양성**: 보드를 화면 가장자리·모서리, 여러 기울기·거리로 찍어야 왜곡계수와 $K$가 잘 분리됨
- **눈 검사(undistort)**: 수치 외에 보정 이미지에서 직선이 곧게 펴지는지 직접 확인

## [파일별 내용]
- `01_calibrate` — 원본 `scripts/calibrate.py`(핵심부) 앞부분, 설정과 3D 기준점
  - `CB = (9, 6)`: 내부 코너 수, `SQ = 0.024`: 한 칸 실측 길이 [m] (주석: 자로 잰 값)
  - `objp`: `(54, 3)` `float32`, `np.mgrid`로 격자 생성 후 `SQ`배
- `02_코너_검출과_캘리브레이션_실행` — 같은 스크립트의 이어지는 부분
  - `shots/*.jpg`를 순회, `findChessboardCorners` 실패한 사진은 이름 출력 후 건너뜀
  - `cornerSubPix(gray, corners, (11, 11), (-1, -1), criteria)`: 탐색 창 반폭 11 px(창 23×23), 데드존 없음
  - `calibrateCamera(..., gray.shape[::-1], None, None)`: 이미지 크기는 `(W, H)` 순서, 초기 $K$·왜곡 없음
  - 반환: `rms`, `K`(3×3), `dist`(1×5: $k_1,k_2,p_1,p_2,k_3$), 장별 `rvecs`/`tvecs`
  - `camera_params.npz`에 `K`, `dist`, `rms`, `image_size` 저장
  - 빠진 맥락: 사진 촬영 단계(`shots/` 폴더 채우기)
- `03_관문_③_눈_검사_undistort` — `cv2.undistort(img, K, dist)` 한 줄, 보정 전후 비교용
- `04_적용_저장_불러오기_즉시_활용` — `np.load("camera_params.npz")`에서 `K`, `dist` 복원
  - 이후 17강 보정, 18·22강 `solvePnP`에 그대로 투입

## [선수 지식·연결]
- 17강: $K$의 각 원소와 방사·접선 왜곡 모델
- 18강: 장마다 구해지는 `rvecs`/`tvecs`가 곧 PnP 결과
- 21강: ROS 2에서는 같은 결과를 `camera_info` YAML(`camera_info_url`)로 제공 → npz에서 YAML 형식으로 옮기는 과정 필요
- 22강: `/camera_info`의 $K$·`dist`로 ArUco PnP와 거리 추정
