# [18강. PnP 포즈 추정과 단안 거리 모호성]
- 모듈: ③ 컴퓨터 비전 + 카메라 모델
- 한 줄 요약: 알고 있는 3D 점과 그 2D 투영의 대응으로 카메라 대비 물체 자세 $[R|t]$를 구하는 PnP 문제와, 단안 카메라가 크기 정보 없이는 거리를 정할 수 없는 이유를 이해하는 강의

## [핵심 개념]
- **PnP(Perspective-n-Point) 문제**
  - 입력: 물체 좌표계의 3D 점 $P_i$, 이미지 점 $p_i$, 내부파라미터 $K$, 왜곡계수
  - 출력: 물체 → 카메라 변환 $R,t$ (6자유도)
  - 목적: 재투영 오차 최소화 $\min_{R,t}\sum_i\|p_i-\pi(K,R,t,P_i)\|^2$
  - 대응점 1개당 식 2개 → 최소 3점(P3P, 해 여러 개), 일반적으로 4점 이상 사용
- **출력 표현**
  - `rvec`: 로드리게스 회전벡터(방향 = 회전축, 크기 = 회전각 rad) → `cv2.Rodrigues`로 $3\times3$ 행렬 변환
  - `tvec`: 카메라 좌표계에서 본 물체 원점 위치, 단위는 `obj_pts`의 단위를 따름
- **재투영 오차로 검증**
  - `cv2.projectPoints`로 3D 점을 다시 투영해 검출 점과의 픽셀 거리 비교
  - 22강에서 임계 초과 포즈를 버리는 기준으로 사용
- **단안 거리 모호성**
  - 투영은 $Z$로 나누므로 크기 $D$, 거리 $Z$인 물체와 크기 $2D$, 거리 $2Z$인 물체가 같은 픽셀로 보임
  - 해결: 실제 크기를 아는 물체(마커·공) 사용 → $Z=\frac{f\cdot D}{d_{px}}$
  - PnP가 거리까지 구할 수 있는 이유도 `obj_pts`에 실측 크기가 들어 있기 때문
- **알고리즘 선택**(`flags`): 기본 반복법(`SOLVEPNP_ITERATIVE`), 평면 정사각형 마커용 `SOLVEPNP_IPPE_SQUARE`, 이상치 대응은 `solvePnPRansac`(24·28강)

## [파일별 내용]
- `01_PnP_문제의_정의` — `ok, rvec, tvec = cv2.solvePnP(obj_pts, img_pts, K, dist)` 한 줄
  - `obj_pts`: `(N, 3)` `float32`, 물체 좌표계의 실측 3D 점(예: 마커 네 꼭짓점)
  - `img_pts`: `(N, 2)` 또는 `(N, 1, 2)` `float32`, **같은 순서**로 대응하는 픽셀 점
  - `K`, `dist`: 17·20강의 내부파라미터와 왜곡계수(왜곡은 함수 내부에서 처리)
  - `ok`: 수렴 여부 → `False`면 `rvec`/`tvec` 사용 금지
  - 빠진 맥락: 대응점을 어디서 얻는가(22강의 ArUco 코너 검출), 결과 검증(재투영 오차)

## [선수 지식·연결]
- 17강: 핀홀 투영식과 $K$, 왜곡계수
- 20강: 실제 $K$·`dist`를 얻는 캘리브레이션
- 22강 경로 A: ArUco 코너 + `solvePnP` + 재투영 오차 필터 → `PoseStamped`
- 22강 경로 B: 크기를 아는 공으로 단안 거리 추정
- 24·28강(M4): P3P·EPnP·RANSAC 심화와 합성 데이터 벤치마크

## [실행 전 준비]
- `pip install opencv-python numpy`
- 실험용으로는 임의의 $R,t$로 3D 점을 `cv2.projectPoints`해 `img_pts`를 만든 뒤 `solvePnP`로 되찾는 방식이 가장 간단

## [확인 포인트]
- 기대 결과: 합성 데이터에서 되찾은 `rvec`/`tvec`가 정답과 거의 일치, 재투영 오차 ≈ 0 px
- 흔한 실수
  - `obj_pts`와 `img_pts`의 점 순서 불일치 → 엉뚱한 포즈
  - 정수형(`int`) 배열 전달 → 형식 오류
  - `obj_pts`를 mm로 넣고 `tvec`을 m로 해석
- 점검 질문
  - `obj_pts`의 크기를 모두 두 배로 키우면 `tvec`은 어떻게 변하는가?
  - 재투영 오차가 작아도 포즈가 틀릴 수 있는 경우는?
  - 한 장의 이미지만으로 공까지의 거리를 알려면 무엇을 알아야 하는가?
