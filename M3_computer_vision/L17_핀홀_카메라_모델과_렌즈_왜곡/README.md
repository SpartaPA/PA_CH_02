# [17강. 핀홀 카메라 모델과 렌즈 왜곡 (내부파라미터 K·방사/접선)]
- 모듈: ③ 컴퓨터 비전 + 카메라 모델
- 한 줄 요약: 3D 점이 픽셀이 되는 핀홀 투영식과 렌즈 왜곡 모델을 이해하고, 이미지 전체 보정과 점 단위 보정의 차이를 아는 강의

## [핵심 개념]
- **핀홀 투영**
  - 카메라 좌표 $(X,Y,Z)$ → 정규화 평면 $x=X/Z,\;y=Y/Z$ → 픽셀 $u=f_x x+c_x,\;v=f_y y+c_y$
  - 전체 사슬: $s\,[u,v,1]^\top=K\,[R\,|\,t]\,[X,Y,Z,1]^\top$
  - $Z$로 나누는 순간 깊이 정보 소실 → 18강 단안 거리 모호성의 근원
- **내부파라미터 $K$**
  - $K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}$
  - $f_x,f_y$: 픽셀 단위 초점거리, $(c_x,c_y)$: 주점(광축이 이미지와 만나는 점)
  - 해상도를 바꾸면 $K$도 비례해 바뀜 → 캘리브레이션 해상도와 사용 해상도 일치 필요
- **외부파라미터 $[R\,|\,t]$**: 월드 → 카메라 좌표 변환(18강 PnP가 구하는 값)
- **렌즈 왜곡 모델**(정규화 좌표, $r^2=x^2+y^2$)
  - 방사: $x_d=x(1+k_1r^2+k_2r^4+k_3r^6)$ → 배럴(볼록)·핀쿠션(오목) 왜곡, 가장자리일수록 큼
  - 접선: $x_d\mathrel{+}=2p_1xy+p_2(r^2+2x^2)$, $y_d\mathrel{+}=p_1(r^2+2y^2)+2p_2xy$ → 렌즈·센서 비정렬
  - OpenCV 계수 순서: `dist_coeffs = [k1, k2, p1, p2, k3]`
- **언제 반드시 보정하나**
  - 픽셀 좌표로 길이·각도·3D 위치를 계산할 때(PnP, 거리 추정)
  - 광각 렌즈이거나 물체가 화면 가장자리에 있을 때
  - 단순 색 검출·표시 용도라면 생략해도 되는 경우가 많음

## [파일별 내용]
- `01_언제_반드시_보정해야_하나` — 두 가지 보정 API 비교(2줄 발췌)
  - `cv2.undistort(img, K, dist_coeffs)`: 이미지 전체를 다시 샘플링 → 보기·시각 검사용, 매 프레임 비용 큼
  - `cv2.undistortPoints(pts, K, dist_coeffs)`: 필요한 점만 보정 → 빠름, PnP 전처리용
  - 주의: `undistortPoints`의 기본 출력은 **정규화 좌표**(픽셀 아님), 픽셀로 받으려면 `P=K` 인자 지정
  - `pts` 형상은 `(N, 1, 2)` `float32`가 안전
  - 빠진 맥락: `img`, `K`, `dist_coeffs`, `pts`의 출처 → 20강 캘리브레이션 결과(`camera_params.npz`)

## [선수 지식·연결]
- 16강: 이미지 배열과 픽셀 좌표 $(u,v)$ = `img[v, u]`
- 9·13강: 동차변환·회전행렬(외부파라미터 $[R|t]$와 같은 형태)
- 18강: $[R|t]$를 2D-3D 대응에서 역으로 구하는 PnP
- 20강: 체커보드로 $K$·`dist` 실제 추정
- 22강 경로 B: 이 투영식의 역방향(역투영)으로 3D 위치 계산

- 흔한 실수
  - `undistortPoints` 출력을 픽셀로 착각해 그대로 그림
  - 다른 해상도에서 얻은 $K$를 그대로 사용
- 점검 질문

  - 이미지 전체 보정 대신 점 보정을 쓰는 것이 유리한 상황은?
  - $f_x$를 두 배로 하면 같은 물체의 픽셀 크기는 어떻게 변하는가?
