# [27강. Stereo·Depth·RGBD와 6D Pose Estimation]
- 모듈: ④ 2D/3D 공간 인지 및 비전 AI
- 한 줄 요약: 하드웨어가 픽셀마다 거리를 재는 원리(스테레오 $Z=fb/d$·구조광·ToF)와 RGBD 정렬을 이해하고, 로봇이 **집으려면** 필요한 6DOF 포즈를 대응(PnP)·정합(ICP)·직접 회귀로 추정하는 흐름을 정리 — 모듈 ④ 이론 편(23~27강)의 마무리
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** 스테레오 원리 $Z=fb/d$를 삼각측량으로 설명하고 **멀수록 부정확한 이유**를 말함
- **필수 ②** 깊이 센서 3계열(수동 스테레오·능동 스테레오/구조광·ToF)의 **강점과 약점** 구분
- **필수 ③** 6D Pose Estimation이 무엇이며 왜 "집으려면" 위치만으로 부족한지 설명
- 심화(선택): ICP 반복 구조, 대칭 물체의 포즈 모호성, RGBD 정렬 내부 계산 — 센서 고르는 감각은 31강 실측에서 완성

## [핵심 개념]
- **출발점**: 18강 "단안은 스케일을 모름" → 깊이를 실제로 얻는 장치 / 검출(25강)은 "무엇이 어느 박스에", 깊이는 "어디에", 파지는 **위치 3 + 자세 3** 필요(컵 손잡이 방향)
- **스테레오 — 두 눈의 삼각측량**
  - 현상: 한 눈씩 감으면 가까운 손가락은 크게 튀고 먼 건물은 거의 그대로 → 어긋난 픽셀 수로 거리를 역산
  - 나란한 두 카메라, 간격 = **베이스라인** $b$, 시차 $d=u_L-u_R$ → 닮은꼴 삼각형 $Z=\dfrac{f\,b}{d}$
  - 단위: $f$ [px], $b$ [m], $d$ [px], $Z$ [m]
  - $d$가 분모 → 가까우면 정확, 멀면 1 px 오차가 큰 거리 오차로 증폭: **$\Delta Z\propto Z^2/(fb)$** → 센서마다 "믿을 만한 유효 범위"가 존재
  - 시차 맵: 픽셀별 시차를 밝기로(밝을수록 가까움) — 깊이 맵과 다른 그림
  - 진짜 난제는 기하가 아니라 **매칭**: 보정(rectification)으로 탐색을 같은 행(1차원)으로 제한 + 블록 매칭(SGBM 등)
  - **무늬 없는 벽·반복 패턴에서 실패** — 매칭 단서가 없음
  - 베이스라인 트레이드오프: 길수록(또는 망원) 원거리 정밀 ↑, 근거리 사각·매칭 난이도 ↑
- **깊이 센서 3계열**

  | 계열 | 원리 | 대표 | 강점 | 약점 |
  |---|---|---|---|---|
  | 수동 스테레오 | 자연 텍스처 매칭 | OAK-D | 야외 OK, 저가 | 무늬 없는 면 실패 |
  | 능동 스테레오/구조광 | 적외선 패턴을 쏘아 텍스처를 "만들어" 매칭 | RealSense D435 | 실내 정밀, 무늬 없는 면 OK | 햇빛(IR 간섭)에 약함 |
  | ToF | 빛의 왕복 시간 | Kinect Azure, LiDAR | 원거리, 프레임 전체 동시 | 다중 반사·정밀도 한계 |

  - 공통 약점: **검은 표면(흡수), 투명·반사 표면(굴절·반사), 물체 경계(혼합 픽셀)** → 구멍(무효 픽셀)·유령 점 = 26강 SOR이 청소하던 노이즈의 출처
- **RGBD 카메라와 정렬(align)**
  - 컬러 카메라 + 깊이 센서 = **물리적으로 다른 위치의 다른 카메라** → 그대로 겹치면 경계에서 색·깊이 어긋남(컵 경계 색 번짐)
  - 정렬 = 깊이 픽셀을 3D로 **역투영** → 컬러 카메라로 **재투영** (23강 좌표 사슬 두 번)
  - SDK가 해 주지만 원리를 알아야 경계 아티팩트 진단 가능 → 31강에서 정렬 전/후 비교
- **6D Pose Estimation — "집을 수 있는" 인지**
  - 문제 정의: 모델이 있는 물체의 센서 기준 $T^{cam}_{obj}\in SE(3)$ (회전 3 + 이동 3) 추정
  - 세 가지 흐름

  | 흐름 | 재료 | 아이디어 | 배운 조각 |
  |---|---|---|---|
  | 대응 기반 | RGB + 모델 키포인트 | 키포인트를 이미지에서 찾아 PnP | 24강 PnP+RANSAC |
  | 정합 기반(ICP) | 깊이/클라우드 + 모델 | 모델 클라우드를 관측에 맞춰 회전·이동 | 26강, Lv.1 27강 Kabsch |
  | 직접 회귀(학습) | RGB(D) + 학습 데이터 | CNN이 포즈를 바로 출력 | 25강 백본 |

- **ICP (Iterative Closest Point)**
  - ① 현재 추정 포즈로 모델 배치 ② 모델 점마다 관측 최근접점을 대응으로 ③ 대응을 가장 잘 맞추는 강체 변환 풀기 = **Kabsch/SVD** ④ 수렴까지 반복
  - 지역 최적 → 좋은 초기 포즈 필수 → **"거친 추정(학습/PPF) → ICP 정제"** 2단이 표준
- **실무 파이프라인**: 검출(25강)로 관심 영역 → 클라우드 잘라내기(26강 클러스터) → 거친 포즈(학습 또는 대응+PnP) → ICP 정제 → 재투영/정합 잔차로 검증
- **물체 후보 추출 흐름**: 장면 클라우드 → 평면 제거 → 클러스터 = 후보 → 크기·형상 1차 선별 → 모델 정합/PnP로 6D 포즈 → 검증 통과분만 하류로
- **(심화) 대칭 물체의 포즈 모호성**
  - 손잡이 없는 원기둥 컵: 축 회전에 대해 무한한 자세, 정육면체: 등가 자세 24개
  - 평가 지표 ADD vs **ADD-S**(대칭 고려), 학습 방법이 정답 여럿을 평균 내 헤매는 원인
  - 처방: 대칭축 명시로 등가 자세 동일 취급, 또는 파지 계획에서 "축 회전 무관"으로 흡수
  - 설계 첫 질문: **"이 물체의 포즈가 유일하게 정의되는가"**

## [용어]
- **시차(disparity)**: 좌우 어긋난 픽셀 수 — 깊이와 반비례
- **베이스라인 $b$**: 두 카메라 간격 — 길수록 좋기만 한 것은 아님(근거리 사각)
- **보정(rectification) vs 왜곡 보정(undistort)**: 두 이미지를 같은 행에 정렬(매칭 1차원화) vs 렌즈 왜곡 제거
- **수동/능동 스테레오**: 자연 무늬 이용 / 패턴을 쏘아 무늬 생성 — 능동식은 햇빛에 약함
- **ToF**: 빛의 왕복 시간 — 다중 반사에 취약
- **RGBD·정렬**: 컬러+깊이, 시점이 달라 깊이를 컬러 시점으로 옮겨야 같은 픽셀
- **6D Pose**: 위치 3 + 자세 3 — 3D 위치만으론 그리퍼 각도 결정 불가
- **ICP**: 두 점 구름 반복 정합 — 초기 포즈가 나쁘면 엉뚱한 곳에 수렴
- **무효 픽셀(hole)**: 센서 고장이 아니라 원리적 한계(검정·투명·반사면)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **깊이 분해능 계산**: D435 근사($f\approx640$ px, $b=5$ cm)로 0.5/1/2/4 m에서 시차 1 px 오차의 깊이 오차 표 작성 ($\Delta Z\approx Z^2/(fb)$ → 약 0.8 / 3.1 / 12.5 / 50 cm)
2. **시차 맵 만들기**: 스테레오 샘플 쌍에 `cv2.StereoSGBM_create` 적용, 무늬 없는 영역·경계 실패를 표시·설명
3. **미니 ICP**: Lv.1 27강 Kabsch 재사용으로 2D 점집합 ICP(최근접 대응 + Kabsch 반복) 구현, 초기 자세를 키워 가며 수렴/발산 경계 관찰 — "거친 추정이 왜 필요한가"
4. **(심화)** 정육면체 등가 자세 24개를 회전 행렬로 생성, 대칭 고려 최소 오차 함수 작성
