# [12강. 동역학·제어 개요 (Lagrange/Newton-Euler·PID 튜닝)]
- 모듈: ② 로봇 기구학 및 동역학
- 한 줄 요약: "왜 움직이는가" — 토크와 운동의 관계 $M\ddot\theta+C\dot\theta+g=\tau$를 **항별로 읽고**, 자세에 따라 바뀌는 플랜트를 관절 독립 PID + **중력 보상 피드포워드**로 다루는 실무 기본기를 이해 — 15강 궤적 추종 실험의 이론
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** $M\ddot\theta+C\dot\theta+g=\tau$의 **세 항**(관성·코리올리·중력)을 말로 설명
- **필수 ②** 로봇 관절 제어가 모듈 ① 단일 모터 제어와 다른 이유 — **플랜트가 자세에 따라 변함** — 설명
- **필수 ③** **중력 보상(피드포워드)** 이 무엇이고 왜 효과적인지 설명
- 심화(선택): Lagrange 유도, 계산 토크 제어, 관성 행렬의 성질 — 손 유도는 요구 수준 아님, 어느 항이 지배적인지 판단하면 충분

## [핵심 개념]
- **기구학 vs 동역학**: 기구학은 움직임의 기하(각도 → 위치, 속도 → 속도), 동역학은 **토크와 운동의 관계**
  - 현상: 같은 게인인데 팔을 뻗으면 처지고 느림, 내릴 땐 빨라지고 올릴 땐 힘겨움, 두 관절을 빠르게 돌리면 안 건드린 관절이 흔들림
  - 원인 셋: 뻗을수록 무거움(피겨 스케이터), 중력이 돕거나 방해, 관절끼리 얹혀 있어 힘이 넘어옴 → **자세에 따라 성격이 바뀌는 플랜트**
- **표준형** (어떤 방법으로 유도해도 같은 꼴)
  - $M(\theta)\ddot\theta+C(\theta,\dot\theta)\dot\theta+g(\theta)=\tau$ — 뉴턴 $F=ma$의 다관절 확장
  - $M(\theta)\ddot\theta$ [kg·m² × rad/s²]: 가속에 저항하는 관성, **뻗을수록 $M$ 증가**
  - $C\dot\theta$ [N·m]: 코리올리·원심, 두 관절이 동시에 빠르게 돌 때만 — 속도 제곱에 비례해 저속에선 무시 가능
  - $g(\theta)$ [N·m]: 가만히 있어도 드는 중력 토크, **수평으로 뻗은 팔에서 최대, 수직이면 0**
  - **저속은 $g$가, 고속은 $M\ddot\theta$·$C\dot\theta$가 지배** → 천천히 움직이는 협동로봇 제어가 상대적으로 쉬운 이유
  - $M$은 대칭·양의 정부호(Lv.1 20강) → 어떤 자세에서도 "음의 질량" 없음
  - 역동역학(운동 → 필요한 토크, 제어기) / 순동역학(토크 → 운동, 시뮬레이터 $\ddot\theta=M^{-1}(\tau-C\dot\theta-g)$)
- **두 가지 유도법**

  | 구분 | Lagrange | Newton-Euler |
  |---|---|---|
  | 아이디어 | 에너지 $L=T-V$, $\frac{d}{dt}\frac{\partial L}{\partial\dot\theta}-\frac{\partial L}{\partial\theta}=\tau$ | 링크마다 힘·모멘트 방정식을 사슬 따라 전파 |
  | 장점 | 체계적, $M\cdot C\cdot g$가 항별로 보임, 구속력 자동 소거 | 빠름 $O(n)$ — 실시간 제어기·시뮬레이터 표준 |
  | 단점 | 관절 수가 늘면 손 계산 폭발 | 항의 물리적 구조가 잘 안 보임 |
  | 쓰임 | 교육·해석·간단한 모델(2링크) | 실시간 역동역학(RNEA), 물리 엔진 |

  - **이해는 Lagrange로, 계산은 Newton-Euler로** — Pinocchio·MuJoCo·Isaac(모듈 ⑧) 내부는 Newton-Euler 계열
- **(심화) 2링크 Lagrange 스케치**
  - $T_i=\frac12m_iv_{ci}^2+\frac12I_i\dot\phi_i^2$, $V_i=m_igy_{ci}$
  - $M_{11}=m_1l_{c1}^2+I_1+m_2(L_1^2+l_{c2}^2+2L_1l_{c2}\cos\theta_2)+I_2$
  - $\cos\theta_2$ 항 → **팔꿈치를 펴면($\theta_2=0$) 관성 최대, 접으면 최소** — "자세 의존 플랜트"가 한 항에 담김 (전체 유도는 Craig 6장)
- **관절 독립 PID와 그 한계**
  - 산업 로봇 기본 구조: 관절마다 독립 PID(7강 심화의 캐스케이드 서보), 다른 관절의 동역학 효과는 전부 **외란**으로 간주
  - 통하는 이유: 감속기 기어비 $N$ → 링크 쪽 동역학이 모터에서 $1/N^2$로 보임 (기어비 100 → 1/10000, 거의 상수 플랜트)
  - 무너지는 곳: ① 고속·고가속 궤적 ② 다이렉트 드라이브·저감속 로봇 ③ **중력** — 평균 0 외란이 아니라 한쪽으로 계속 미는 힘 → P·D만으론 처지고, I로 버티면 자세가 바뀔 때마다 다시 쌓아야 함
- **처방 1 — 중력 보상** (가장 중요한 실무 기법)
  - $g(\theta)$는 자세만 알면 계산 가능 → PID에 맡기지 말고 미리 먹여 줌
  - $\tau=\underbrace{K_pe+K_i\!\int e+K_d\dot e}_{\text{피드백}}+\underbrace{\hat g(\theta)}_{\text{피드포워드}}$
  - 피드백은 오차가 생긴 뒤 반응(중력 아래 항상 조금 처짐), 피드포워드는 오차 전에 필요한 힘 → 피드백은 **모델이 못 맞춘 나머지**만 담당
  - $\hat g$ = 추정값, 실제와의 차이는 피드백이 메움
  - 수평 유지 실험: PD만 → 처진 채 정착 / PD+I → 오차는 없어지나 적분이 쌓이는 동안 느린 복귀 / PD+중력 보상 → 처음부터 안 처짐
  - 협동로봇 **"무중력 모드"**(손으로 끌면 따라오는 교시) = $\tau=\hat g(\theta)$만 내보내는 상태
- **처방 2 — 계산 토크 제어 (예고)**
  - $\tau=M(\theta)(\ddot\theta_d+K_pe+K_d\dot e)+C\dot\theta+g$ → 플랜트를 통째로 상쇄, 어느 자세에서든 균일 성능
  - 모델 정확도가 관건, Lv.3 고급 제어 주제
- **튜닝 재점검 (15강 스펙)**
  - 3강 절차(P→I→D, 계단 응답 지표) 그대로
  - 달라지는 점: ① **최악 자세(팔 뻗음, 관성 최대)에서 튜닝**, 다른 자세에서 검증 ② 목표가 궤적(Quintic) → **RMS 추종 오차** 지표 추가

## [용어]
- **동역학 vs 기구학**: 힘·토크와 운동의 관계 vs 힘을 묻지 않는 기하
- **관성 행렬 $M(\theta)$**: 자세에 따라 변하는 "무거움" — 스칼라 질량이 아니라 관절 간 결합까지 담은 행렬
- **코리올리·원심 항 $C\dot\theta$**: 관절들이 얽혀 만드는 힘, 속도 제곱 비례
- **중력 항 $g(\theta)$**: 평균 0 외란이 아니라 한쪽으로 계속 미는 힘
- **역동역학 / 순동역학**: 같은 식을 어느 방향으로 푸는가 — 제어기 설계 / 시뮬레이터
- **피드포워드**: 오차 전에 미리 주는 명령 — 피드백과 배타적이지 않고 함께 씀
- **중력 보상 vs 계산 토크 제어**: 중력만 미리 vs 동역학 전체 상쇄(모델 정확도 의존)
- **감속기(기어비 $N$)**: 링크 동역학을 $1/N^2$로 작게 보이게 함 — 대신 백래시·마찰 유입
- **RMS 추종 오차**: 궤적 추종 정확도 — 오버슈트·정착시간과 다른 지표

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **항 크기 어림**: $m_2=1$ kg, $L_1=0.3$ m, $l_{c2}=0.1$ m 팔이 수평일 때 관절 2 중력 토크 어림 → SG90 정격(약 0.18 N·m)으로 들 수 있는지 판정 (약 $1\times9.81\times0.1\approx0.98$ N·m → 불가)
2. **중력 토크 곡선**: $g_2(\theta)=m_2g\,l_{c2}\cos(\theta_1+\theta_2)$를 자세별로 그려 최대·0 자세 표시
3. **중력 보상 시뮬레이션**: 단진자 $\ddot\theta=(\tau-mgl\cos\theta)/I$를 오일러 적분 → (가) PD만 (나) PD+중력 보상 계단 응답 비교 (15강 맛보기)
4. **(심화)** $M_{11}(\theta_2)$를 그려 관성 최대/최소 비를 구하고 "최악 자세에서 튜닝" 지침을 수치로 뒷받침
