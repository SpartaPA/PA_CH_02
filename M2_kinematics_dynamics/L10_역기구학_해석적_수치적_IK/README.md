# [10강. 역기구학 (해석적·수치적 IK: Newton-Raphson·Jacobian Pseudo-Inverse)]
- 모듈: ② 로봇 기구학 및 동역학
- 한 줄 요약: 목표 손끝 위치 → 관절 각을 찾는 **비선형 역문제** — 2링크는 코사인 법칙으로 닫힌 식(elbow-up/down 두 해), 임의 구조는 Jacobian으로 "추측 → 오차 → 수정"을 반복하는 수치적 IK로 풂
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** IK의 해가 **없거나·여러 개거나·무한할 수 있음**을 그림과 예로 설명
- **필수 ②** 2링크 해석적 IK를 코사인 법칙으로 풀고 $\pm$ 부호가 **elbow-up/down**임을 앎
- **필수 ③** 수치적 IK의 반복 구조(추측 → 오차 → $J$로 수정)를 말로 설명
- 심화(선택): 유사역행렬의 최소 노름 성질, damped least squares, 초기 추측 관리 — $J^+$ 손계산은 불필요, **왜 필요하고 언제 위험한지**만

## [핵심 개념]
- **IK 문제**: $f(\theta)=T_{\text{목표}}$에서 $\theta=?$ — 현장 질문("저 부품을 집으려면 관절을 몇 도로?")은 대부분 이 방향
  - $\sin\cdot\cos$이 얽힌 **비선형 연립방정식** → 가우스 소거(선형 도구) 불가
  - 두 갈래: 해석적(닫힌 식) / 수치적(반복 근사)
- **해의 세 가지 운명** (FK의 "항상 유일"과 대비)
  - 해 없음: 목표가 작업 공간 밖, 또는 닿아도 관절 한계에 걸림
  - 복수 해: 같은 손끝, 다른 관절 배치 — 6축 산업 로봇은 보통 **최대 8개** / 어느 해를 고를지(현재 자세에 가까운 해, 충돌 없는 해)는 별개의 설계 문제
  - 무한 해: 여유 자유도 — 팔꿈치를 돌려도 손끝 그대로, 해가 연속체
  - 예: 문손잡이 잡기(팔꿈치 위/아래), 등 뒤 2 m 물건(해 없음)
- **해석적 IK — 2링크 팔**
  - 직관: 두 링크 + 베이스–목표 거리 $r=\sqrt{x^2+y^2}$ = 삼각형 하나 → 위로/아래로 접기 = 두 해, 삼각형 불성립 = 해 없음
  - $D\equiv\cos\theta_2=\dfrac{x^2+y^2-L_1^2-L_2^2}{2L_1L_2}$
  - $\theta_2=\mathrm{atan2}(\pm\sqrt{1-D^2},\,D)$
  - $\theta_1=\mathrm{atan2}(y,x)-\mathrm{atan2}(L_2\sin\theta_2,\;L_1+L_2\cos\theta_2)$ — 첫 항 "목표를 바라보는 방향", 둘째 항 "둘째 링크 때문의 보정각"
  - $D\to1$: 팔이 펴짐(먼 목표), $D\to-1$: 팔이 접힘(가까운 목표)
  - **$|D|>1$ → 해 없음** (코드 첫 줄 `if abs(D) > 1: return None`)
  - $\pm$ = elbow-up/down (부호 선택 인자 `elbow_up=True`)
  - $\arccos$ 대신 **atan2**: 사분면 구분 + $|D|\approx1$ 근처 수치 안정성(Lv.1 21강)
  - 장점: 마이크로초, 정확, 모든 해 명시 / 단점: 구조마다 손 유도, 6축 임의 구조는 식이 없을 수 있음
- **수치적 IK — Newton-Raphson**
  - 재료: 작은 변화의 선형 근사 $\Delta x\approx J(\theta)\Delta\theta$ (Jacobian = 11강 주인공을 미리 사용)
  - 오차 $e=x_{\text{목표}}-f(\theta_k)$ → $\theta_{k+1}=\theta_k+J^{-1}(\theta_k)\,e$
  - $J$ = "관절을 틀면 손끝이 이만큼"의 환율 [m/rad], $J^{-1}$ = 거꾸로 된 환율 [rad/m] → 남은 오차를 관절 언어로 번역해 한 걸음
  - 근사라 한 번에 안 맞아 반복, 목표 근처에선 **2차 수렴**(반복당 자릿수 배로) — 보통 5~20회면 mm 이하
  - 실무 형태: 허용 오차(`norm(e) < 1e-4`) + 최대 반복 횟수
- **Jacobian Pseudo-Inverse — $J$가 정사각이 아닐 때**
  - 관절 수 ≠ 작업 공간 차원(여유 자유도, 평면 위치만 제어하는 3링크 등) → $J^{-1}$ 없음
  - $\Delta\theta=J^+e$, $J^+=J^\top(JJ^\top)^{-1}$ (관절이 남을 때)
  - 무한 해 중 **관절 변화가 최소인 해**(최소 노름) 선택 — Lv.1 19강 최소자승의 재등장
  - NumPy `np.linalg.pinv(J) @ e` (내부는 SVD, Lv.1 20강)
  - 특이점 근처: $J$가 계급을 잃어 $\Delta\theta$ 폭발 → **damped least squares** $J^\top(JJ^\top+\lambda^2I)^{-1}$로 방어 (14강 비교)
- **해석적 vs 수치적**

  | 구분 | 해석적 (닫힌 식) | 수치적 (NR·pseudo-inverse) |
  |---|---|---|
  | 적용 범위 | 구조마다 유도, 안 되는 구조도 있음 | 임의 구조 공통 |
  | 속도 | 마이크로초, 결정적 | 반복 — 수십~수백 µs, 가변 |
  | 해의 파악 | 모든 해 명시 (elbow 선택 가능) | 초기 추측 근처의 한 해만 |
  | 실패 모드 | $\lvert D\rvert>1$ 판별로 명확 | 수렴 실패·특이점 발산 → 안전장치 필요 |
  | 실무 | 6축 산업 로봇 제어기 내부 | 여유 자유도·휴머노이드·MoveIt·IKPy |

- **(심화) 초기 추측이 운명을 정함**
  - 수치 IK는 $\theta_0$ 근처 해로 수렴
  - 연속 동작 중엔 **직전 주기의 해를 초기값**으로 → 해가 튀지 않음(elbow 뒤집힘 없음), 1~2회 반복으로 끝
  - 정지 상태 먼 목표는 여러 초기값을 뿌려 복수 해 탐색
  - "IK 솔버가 가끔 팔을 홱 뒤집는다" 버그 대부분이 초기 추측 관리 문제

## [용어]
- **IK vs FK**: 방향이 반대이고 난이도가 전혀 다름 — 실제 명령은 대부분 작업 공간에서 옴
- **해석적 해 vs 수치적 해**: 공식 한 줄로 모든 해 vs 반복 계산으로 초기 추측 근처 한 해
- **elbow-up / elbow-down**: 같은 손끝, 다른 관절 — 둘 다 정답, 선택은 별도 판단(충돌 회피 활용)
- **여유 자유도**: 해가 무한하다는 뜻이지 "더 정확하다"는 뜻이 아님
- **atan2**: 사분면까지 구분 — `atan(y/x)`는 사분면 정보 상실
- **Jacobian $J$**: 관절 속도 → 손끝 속도 환율, 위치가 아니라 변화율 사이의 관계
- **유사역행렬 $J^+$**: 비정사각 행렬의 역행렬 대용 — 진짜 역이 아니라 오차가 남을 수 있음
- **damped least squares**: 특이점 근처 브레이크 — 정확도를 조금 포기하는 안전장치
- **수렴 허용 오차**: 너무 작으면 안 끝나고, 너무 크면 부정확
