# [9강. 순기구학 (D-H 파라미터·동차변환·Forward Kinematics)]
- 모듈: ② 로봇 기구학 및 동역학
- 한 줄 요약: 링크마다 좌표계를 붙이고 **이웃 동차변환을 곱해** 관절 각 → 손끝 위치·자세를 구하는 순기구학(FK)과, 이웃 변환을 숫자 4개로 적는 D-H 규약을 이해 — Lv.1 좌표 체인에 "관절 변수"가 들어간 것뿐
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** 링크·조인트·자유도·엔드이펙터 어휘로 로봇팔 구조 설명
- **필수 ②** "이웃 변환을 곱하면 베이스→손끝"이라는 FK 원리를 말하고 2링크 팔의 $x,y$ 식을 직접 쓰기
- **필수 ③** 완성된 $T^0_n$에서 **위치(마지막 열)** 와 **자세(왼쪽 위 3×3)** 를 구분해 읽기
- 심화(선택): standard/modified D-H 차이, D-H의 한계와 현대 대안, D-H 표 직접 작성 (남이 준 표를 공식에 넣어 곱할 수 있으면 필수 통과)

## [핵심 개념]
- **FK의 정의**: $T_{\text{end}}=f(\theta_1,\dots,\theta_n)$ — 관절 각을 넣으면 손끝 위치·자세가 나오는 함수
  - 새 수학이 아니라 Lv.1 동차변환(23·24강 좌표 체인)에 관절 변수를 끼워 곱하는 것
  - Lv.1 체인은 고정 변환, 로봇팔은 **변환 안에 변수**가 있다는 점만 다름
- **로봇팔의 어휘**
  - 링크(강체 막대)가 조인트로 이어진 사슬, 시작 = 베이스, 끝 = 엔드이펙터
  - 회전 조인트(R): 변수 $\theta$ / 직동 조인트(P): 변수 $d$
  - 자유도(DOF): 독립 관절 변수 수 — 공간 위치(3)+자세(3) 임의 지정에 최소 **6DOF** → 산업용 팔 대부분 6축
  - 사람 팔 = 어깨 3 + 팔꿈치 1 + 손목 3 = 7DOF → **여유 자유도(redundancy)**, 10강 IK의 "해가 무한히 많음"
  - 실습(13강)은 평면 2~3DOF — 원리는 6축과 동일, 손 검산 가능
- **왜 링크마다 좌표계를 붙이나 — 분할 정복**
  - 손끝 식을 한 번에 쓰면 삼각함수가 눈덩이처럼 불어남 (지하철 노선도: 역 사이 한 구간씩만 알면 됨)
  - 링크 $i$마다 좌표계 $\{i\}$, 이웃 변환 $T^{i-1}_i$만 정의 → $T^0_n=T^0_1T^1_2\cdots T^{n-1}_n$
  - 곱 순서: 왼쪽이 베이스 쪽 (Lv.1 23강 규칙)
- **2링크 평면 팔 손 풀기**
  - $T^0_1=\mathrm{Rot}_z(\theta_1)\mathrm{Trans}_x(L_1)$, $T^1_2=\mathrm{Rot}_z(\theta_2)\mathrm{Trans}_x(L_2)$
  - $x=L_1\cos\theta_1+L_2\cos(\theta_1+\theta_2)$, $y=L_1\sin\theta_1+L_2\sin(\theta_1+\theta_2)$
  - 두 링크 벡터의 덧셈, 둘째 항 각이 $\theta_1+\theta_2$인 이유 = 둘째 링크가 첫째 링크 위에 얹혀 함께 돎($\theta_2$는 상대 각)
  - 손 검산: $\theta_1=\theta_2=0$ → $(L_1+L_2,0)$ 쭉 뻗은 팔 / $\theta_2=90°$ → 팔꿈치 직각
  - 13강 `PlanarArm.fk()` 반환값 = 이 $(x,y)$, 14강 Jacobian = 이 두 줄의 편미분
- **D-H 파라미터 — 좌표계 붙이기의 표준 규약**
  - 아무렇게나 붙이면 사람마다 변환이 다름 → 이웃 변환을 **항상 숫자 4개**로

  | 파라미터 | 이름 | 의미 |
  |---|---|---|
  | $\theta_i$ | 관절각 | $z_{i-1}$축 둘레 회전 (회전 조인트 변수) |
  | $d_i$ | 링크 오프셋 | $z_{i-1}$축 방향 이동 (직동 조인트 변수) |
  | $a_i$ | 링크 길이 | $x_i$축(공통 수직선) 방향 이동 |
  | $\alpha_i$ | 링크 비틀림 | $x_i$축 둘레 회전 (이웃 관절축 사이 각) |

  - $T^{i-1}_i=\mathrm{Rot}_z(\theta_i)\mathrm{Trans}_z(d_i)\mathrm{Trans}_x(a_i)\mathrm{Rot}_x(\alpha_i)$ — "돌고(θ)·오르고(d)·뻗고(a)·비틀고(α)"
  - 결과 행렬: 마지막 열 $(a_ic\theta_i,\;a_is\theta_i,\;d_i)$, 3행 $(0,\;s\alpha_i,\;c\alpha_i)$
  - 순서가 고정돼 있다는 것이 규약의 핵심 → 같은 로봇은 누가 적어도 같은 표
  - 회전 관절이면 $\theta_i$만 변수, 나머지 셋은 기계 도면 상수 → 로봇 하나 = **D-H 표 한 장**
  - 2링크 평면 팔 표: 행 $i=1,2$ 각각 $(\theta_i\text{ 변수},\,d=0,\,a=L_i,\,\alpha=0)$ → 곱하면 손 계산과 동일
  - 13강 `dh_transform(theta, d, a, alpha)`가 이 곱 그대로, 링크가 늘어도 표에 줄만 추가
- **(심화) D-H의 함정과 현대 대안**
  - 규약이 두 종류(standard/modified) → 남의 표는 규약부터 확인
  - 이웃 관절축이 평행하면 좌표계 배치가 유일하지 않아 수치적으로 민감
  - URDF(ROS2)·Pinocchio·Drake는 "관절 축 벡터 + 원점 오프셋" 직접 기술(product of exponentials 계열)
  - 그래도 배우는 이유: 산업 로봇 매뉴얼·논문·시험이 여전히 D-H 사용
- **FK 출력 읽기**: $T^0_n=\begin{bmatrix}R_{3\times3}&p_{3\times1}\\0&1\end{bmatrix}$
  - $p$ = 위치(마지막 열), $R$ = 자세 → 필요 시 오일러 각·쿼터니언 변환(Lv.1 18·20강)
  - **FK는 항상 유일·항상 계산 가능** / 반대 방향(IK)은 해 없음·여러 개·무한 가능 → 10강
- **작업 공간(workspace)**: FK를 모든 관절 조합에 평가한 손끝 도달 영역
  - 2링크 팔 → 반지름 $|L_1-L_2|\sim L_1+L_2$의 고리(annulus)
  - "이 로봇이 거기까지 닿나?" = 로봇 선정·배치 설계의 첫 질문이자 FK 문제

## [용어]
- **링크 vs 조인트**: 링크는 뼈대 막대, 조인트는 그 사이의 관절 — 움직임(변수)이 생기는 유일한 곳
- **자유도(DOF)**: 관절 수와 대체로 같지만 구속이 있으면 달라짐
- **엔드이펙터 vs TCP**: 엔드이펙터는 그리퍼·툴, TCP(Tool Center Point)는 그 위의 기준점
- **FK vs IK**: FK는 관절 각 → 손끝(유일), IK는 반대 방향(훨씬 어려움, 10강)
- **동차변환 $T$**: 회전+이동을 담은 4×4 — 3×3 회전 행렬만으로는 이동 표현 불가
- **D-H 파라미터**: 이웃 링크 관계를 적는 네 숫자 — 규약 두 종류라 출처 확인 필수
- **베이스 좌표계 {0}**: 모든 위치의 기준 — 로봇이 이동체 위에 있으면 월드 좌표계와 다름
- **작업 공간 vs 관절 공간**: 손끝이 닿는 영역 vs 관절 각도들의 공간
