# [4강. MCU와 주변장치 (Cortex-M·GPIO·인터럽트·타이머·PWM)]
- 모듈: ① 임베디드 제어 기초
- 한 줄 요약: Cortex-M MCU에서 주변장치는 메모리 주소에 매핑된 레지스터이며, 같은 동작을 레지스터 직접 조작과 HAL 함수 두 방식으로 표현할 수 있음을 이해

## [핵심 개념]
- 메모리 맵 I/O
  - 주변장치(GPIO·타이머·ADC·UART)의 설정·상태가 고정 주소의 레지스터에 위치
  - 포인터로 그 주소에 읽기/쓰기 = 하드웨어 조작
  - `GPIOA->ODR`: 구조체 포인터로 레지스터 묶음에 이름을 붙인 CMSIS 방식
- GPIO 레지스터 역할(STM32 계열 일반)
  - MODER: 입력/출력/대체기능/아날로그 모드
  - ODR: 출력 데이터, IDR: 입력 데이터, BSRR: 원자적 set/reset
- 비트 연산
  - 세트: `reg |= (1 << n)`, 클리어: `reg &= ~(1 << n)`, 토글: `reg ^= (1 << n)`
  - 읽기-수정-쓰기(RMW)는 인터럽트와 경합 시 원자성 문제 → BSRR이나 HAL 사용
- bare-metal vs HAL
  - bare-metal: 빠르고 투명, 칩 의존적
  - HAL: 이식성·가독성, 약간의 오버헤드
- 인터럽트(NVIC): 이벤트 발생 시 메인 흐름을 멈추고 ISR 실행 → 5강 EXTI, 7강 타이머 ISR
- 타이머·PWM
  - 클럭을 분주(PSC)해 카운트, 자동 재장전값(ARR)에서 주기 결정
  - 비교값(CCR)과 카운터 비교로 PWM 듀티 생성 → 5강 실습

## [파일별 내용]
- `01_메모리맵_모든_것은_주소다.c` — GPIOA 5번 핀을 High로 만드는 같은 동작의 두 표현
  - `GPIOA->ODR |= (1 << 5);`: 출력 데이터 레지스터 5번 비트 직접 세트
  - `HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);`: HAL 함수 호출
  - 발췌: 클럭 활성화(RCC)와 핀 모드 출력 설정이 앞에 선행되어야 실제로 동작
  - PA5는 5강에서 보드 LED(`LD2`)로 사용
