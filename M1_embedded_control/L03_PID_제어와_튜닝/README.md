# [3강. PID 제어와 튜닝 (P·I·D·Ziegler–Nichols·anti-windup)]
- 모듈: ① 임베디드 제어 기초
- 한 줄 요약: 연속 PID를 MCU에서 도는 이산 코드로 바꾸고, 출력 포화 시 적분이 쌓이는 windup을 막는 방법 이해

## [핵심 개념]
- 연속 PID: $u=K_pe+K_i\int e\,dt+K_d\dot e$, $e=r-y$
  - P: 현재 오차에 비례 → 반응 속도, 단독이면 정상상태 오차 잔존 가능
  - I: 오차 누적 → 정상상태 오차 제거, 과하면 오버슈트·진동
  - D: 오차 변화율 → 제동(감쇠) 효과, 노이즈에 민감
- 이산화(주기 $dt$마다 한 번 계산)
  - 적분 → 누적합(사각형 근사): $I_k=I_{k-1}+e_k\,dt$
  - 미분 → 후진 차분: $D_k=(e_k-e_{k-1})/dt$
  - $dt$가 일정해야 계수 의미가 유지 → 7강에서 타이머 인터럽트로 주기 고정
- 튜닝
  - 수동: $K_p$ → $K_d$ → $K_i$ 순으로 올리며 응답 관찰
  - Ziegler–Nichols(한계감도법): P만으로 지속 진동이 나는 한계 이득 $K_u$와 주기 $T_u$를 찾아 표로 계수 결정(고전 표: $K_p=0.6K_u$, $T_i=T_u/2$, $T_d=T_u/8$)
- windup
  - 액추에이터 포화(예: 듀티 ±100%) 중에도 적분이 계속 커짐
  - 목표 도달 후 쌓인 적분을 소진할 때까지 큰 오버슈트 발생
  - 대책(anti-windup): 포화 중 오차가 포화 방향으로 미는 경우 적분을 쌓지 않음(clamping)
- D 항의 실전 수정(7강에서 적용): 측정값 미분(derivative on measurement), 미분 EMA 필터

## [파일별 내용]
- `01_이산화_MCU_위의_PID.c` — 가장 단순한 이산 PID 함수 `pid_step(PID *c, float ref, float meas, float dt)`
  - `c->integral += e * dt`: 사각형 근사 적분
  - `deriv = (e - c->e_prev) / dt`: 오차의 차분 미분
  - 반환값: 포화 처리 없는 제어 출력
  - 발췌: `PID` 구조체(`Kp, Ki, Kd, integral, e_prev`) 정의는 생략됨
- `02_대표_대책_anti_windup.c` — `pid_step` 내부에 끼울 포화·anti-windup 조각
  - `U_MAX`/`U_MIN`으로 출력 제한
  - 포화 + 오차가 같은 방향이면 `c->integral -= e*dt`로 이번 주기에 쌓은 적분을 취소
  - 발췌: `e`, `deriv`, `U_MAX`, `U_MIN` 정의와 `return u;`는 앞뒤 맥락에 있음
  - 01의 적분 누적 뒤에 실행된다는 전제(먼저 더하고 필요하면 되돌림)

## [선수 지식·연결]
- 1강: 오버슈트·정착시간 개념(튜닝 결과를 판정하는 기준)
- 7강 `02_PID_모듈_구현.c`: 이 코드를 구조체·조건부 적분·D 필터까지 갖춘 모듈로 완성
- 7강 `03_ISR에서_조립.c`: 주석의 "7강에서 타이머 인터럽트로 구동"
- 15강: 로봇팔 관절별 PID와 중력 보상

## [실행 전 준비]
- 단독 실행 불가(함수 조각) → STM32CubeIDE HAL 프로젝트의 `USER CODE` 구역에 삽입
- PC에서 C 컴파일러로 간단한 1차 플랜트 시뮬레이션 루프를 만들어 시험해 보는 것도 가능

## [확인 포인트]
- `dt`를 실제 호출 주기와 다르게 넣으면 $K_i$, $K_d$의 실효값이 달라짐
- 목표값 계단 변화 시 오차 미분이 순간적으로 커지는 derivative kick → 7강의 측정값 미분으로 해결
