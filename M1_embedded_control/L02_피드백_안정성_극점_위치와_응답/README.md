# [2강. 피드백 안정성 (극점 위치와 응답)]
- 모듈: ① 임베디드 제어 기초
- 한 줄 요약: "왜 로봇이 발진하는가"를 **극점 위치** 하나로 판별하고, 피드백 이득을 키우면 극점이 움직여 결국 불안정해지는 이유를 이해 — 3강 PID 튜닝 전에 갖출 안전 감각
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** 안정·한계 안정·불안정 세 계단 응답을 그래프만 보고 구분
- **필수 ②** "모든 극점이 s-평면 왼쪽이면 안정" 규칙을 말하고 지도에 위치를 찍기
- **필수 ③** 이득을 키우면 빨라지다가 결국 발진하는 이유를 **지연**(샤워기 비유)으로 설명
- 심화(선택): $t_s\approx4/\sigma$, 특성방정식 $1+K_pG(s)=0$ 직접 풀기

## [핵심 개념]
- **피드백이 불안정을 만드는 직관 — 샤워기**
  - 배관 지연 때문에 지금 느끼는 온도 = 몇 초 전 밸브 위치의 결과
  - 지나간 오차에 세게 보정 → 결과가 늦게 도착 → 과잉 보정 반복 → 진동이 점점 커짐
  - 오차를 줄이려는 행동이 **너무 세거나 너무 늦으면** 보정이 다음 오차를 키움
- **BIBO 안정성**
  - 유한한 입력(Bounded Input)에 출력도 항상 유한(Bounded Output)하면 안정
  - 세 가지 운명
    - 안정: 어떤 값에 수렴 (감쇠 진동하며 수렴해도 안정 — 1강 $\zeta=0.3$ 곡선)
    - 한계 안정: 일정 진폭으로 영원히 진동
    - 불안정: 지수적으로 발산 (실기에서는 진동하며 커지는 형태가 가장 흔함)
  - 예: 마이크 하울링(루프 이득 > 1에서 발산), 저속 자전거(조건에 따라 안정성이 달라짐)
- **극점(pole) = 전달함수 분모를 0으로 만드는 $s$**
  - 1차계 $G(s)=\frac{K}{\tau s+1}$ → $s=-\frac1\tau$
  - 2차계 → $s=-\zeta\omega_n\pm j\omega_n\sqrt{1-\zeta^2}$
  - 시간응답은 항상 극점을 지수로 갖는 항들의 합
  - 극점 $s=a+jb$ → 응답 항 $e^{(a+jb)t}=e^{at}(\cos bt+j\sin bt)$
    - 실수부 $a$ [1/s]: 진폭의 운명(포락선) — 음수면 수렴, 양수면 발산
    - 허수부 $b$ [rad/s]: 출렁임 — 있으면 진동, 클수록 빠르게 진동
- **s-평면 지도 읽기**
  - 가로축 = 실수부(감쇠율, 시간 아님), 세로축 = 허수부
  - 왼쪽 = 수렴, 오른쪽 = 발산, 허수축 위 = 지속 진동
  - 왼쪽으로 깊을수록 빨리 정착, 실수축에서 멀수록 빠르게 진동
  - **판별 규칙: 모든 극점 실수부 < 0 → 안정 / 하나라도 오른쪽 → 불안정 / 허수축 위 → 한계 안정**
- **1강 지표를 극점으로 다시 읽기**

  | 1강 언어 | 극점 위치 | 응답 |
  |---|---|---|
  | 1차 시스템 | 실수축 왼쪽 (예: $s=-1/\tau$) | 진동 없는 지수 수렴 |
  | 2차, $0<\zeta<1$ | 왼쪽 복소켤레쌍 | 감쇠 진동 (오버슈트) |
  | 2차, $\zeta=1$ | 실수축 왼쪽 중근 | 임계 감쇠 — 진동 없이 최속 |
  | $\zeta=0$ | 허수축 위 켤레쌍 | 일정 진폭 지속 진동 |
  | — | 오른쪽 아무 데나 | 발산 |

- **(심화) 극점 실수부와 정착시간**
  - 실수부 $a=-\sigma$ → 포락선 $e^{-\sigma t}$ → $t_s\approx4/\sigma$
  - 1강 $t_s\approx4/(\zeta\omega_n)$과 같은 식 (2차 극점 실수부가 $-\zeta\omega_n$)
  - "극점을 왼쪽으로 민다" = "정착시간을 줄인다" → pole placement 관점(Lv.3 상태공간 제어)
- **피드백은 극점을 옮긴다**
  - 플랜트 $G(s)$에 이득 $K_p$로 되먹임 → 폐루프 $T(s)=\frac{K_pG(s)}{1+K_pG(s)}$
  - 폐루프 극점 = 플랜트 극점이 아니라 **$1+K_pG(s)=0$의 해** → $K_p$는 극점 이동량을 정하는 손잡이
  - $K_p$가 클수록 $T(s)\to1$ → "게인이 크면 목표를 잘 따라간다"의 수식 표현
  - 좋은 면: 극점을 왼쪽으로 밀어 빠르게, 원래 불안정한 시스템(도립진자, 이족 로봇, 세그웨이)도 안정화 — 불안정 시스템은 피드백 없이 못 씀
  - 나쁜 면: 이득을 키우다 극점이 오른쪽으로 넘어가면 안정하던 시스템이 발진
  - 교안 그림: 같은 플랜트에 $K_p=1\to5\to20$ → 켤레 극점이 허수축 쪽으로 이동, $K_p=20$에서 발산
- **왜 이득을 키우면 불안정해지나 — 지연**
  - 실제 시스템엔 반드시 지연: 센서 처리·통신·액추에이터 반응·제어 주기 자체
  - 제어기는 항상 조금 전의 오차를 보고 반응 → 큰 이득은 지나간 오차에 과잉 반응 → 진동 성장
  - 실무 감각: 제어 주기가 길수록(지연↑) 쓸 수 있는 최대 이득↓ → 7강 제어 주기 1 kHz의 이유
  - 격언: "루프를 느리게 돌리면서 게인만 키우면 반드시 발진"
- **(심화) 한계 이득 $K_u$·한계 주기 $T_u$ — 3강 예고**
  - 이득을 서서히 키우면 $K_u$에서 극점이 정확히 허수축 → 주기 $T_u$의 지속 진동
  - 위험의 경계이자 **Ziegler–Nichols 튜닝의 입력값**(3강)

## [용어]
- **안정성(BIBO)**: 정확도와 다름 — 안정해도 정상상태 오차가 남을 수 있음
- **극점 vs 영점**: 극점은 분모를 0, 영점(zero)은 분자를 0으로 만드는 값
- **발진**: 진폭이 스스로 커지는 떨림 — 진폭이 줄어드는 감쇠 진동과 구분, 실기 중단 기준
- **한계 이득 $K_u$**: 발진 직전 게인 — 최적 게인이 아니며 실제 사용 게인은 훨씬 낮음
- **한계 주기 $T_u$**: 발진 주기 [s] — 제어 주기 $dt$(1 ms 등)와 전혀 다른 값
- **루프 이득**: 한 바퀴 돌아온 신호의 배율 — $K_p$만이 아니라 플랜트·센서 포함
- **지연 vs 시정수**: 시정수는 "천천히 반응", 지연은 "한동안 아무 반응 없음"

## [선수 지식·연결]
- 1강: 전달함수, 1·2차 계단 응답, $\zeta$·$\omega_n$, $t_s\approx4/(\zeta\omega_n)$ → [L01 README](../L01_제어_개요와_시스템_응답/README.md)
- 3강: 한계 이득 $K_u$·한계 주기 $T_u$를 Ziegler–Nichols 튜닝에 그대로 사용 → [L03](../L03_PID_제어와_튜닝/)
- 7강: 게인을 올리며 로그에서 "진폭이 커지는 진동"($a>0$) 관찰, 제어 주기 1 kHz 선택 근거 → [L07](../L07_PID_펌웨어_목표값_추종/)
- 로그에서 극점 어림: 진동 주기 $T$ → $b=2\pi/T$, 진폭이 절반 되는 시간 → $a$

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **극점 → 응답 예측**: (가) $s=-5$ (나) $s=-1\pm5j$ (다) $s=+0.5\pm2j$ (라) $s=\pm4j$ 각각 수렴/발산/지속진동·진동 유무를 손으로 예측 → 노트북에서 $y(t)=e^{at}\cos(bt)$를 그려 검증
2. **게인 스윕**: $G(s)=\frac{1}{s(s+1)(s+3)}$에 비례 이득 → `python-control`(`pip install control`)의 `feedback(Kp*G, 1)`로 폐루프 구성, $K_p\in\{1,5,12,20\}$ 계단 응답을 겹쳐 그려 발진이 시작되는 구간 기록
3. **일상의 불안정 분석**: 하울링·샤워기·저속 자전거 중 하나를 골라 센서·액추에이터·지연·이득을 대응시켜 다섯 문장으로 분석
4. **(심화)** 과제 2 시스템의 $K_u$를 이분 탐색으로 소수점 한 자리까지, $T_u$를 그래프에서 측정 → **3강 실습에서 다시 사용**
