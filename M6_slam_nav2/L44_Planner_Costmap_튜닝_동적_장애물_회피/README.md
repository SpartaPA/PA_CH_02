# [44강. [실습] Planner/Costmap 튜닝·동적 장애물 회피]
- 모듈: ⑥ SLAM 및 Nav2 자율주행
- 한 줄 요약: 플래너·컨트롤러·costmap 파라미터를 바꿔 동적 장애물 회피를 개선하되, 회귀 게이트(여러 시나리오 비교)를 통과한 변경만 채택하는 튜닝 절차

## [핵심 개념]
- **costmap 레이어**
  - static: 저장 지도 기반 고정 장애물
  - obstacle: 센서(이번 구성은 nvblox) 기반 실시간 장애물 → 동적 장애물 반영의 핵심
  - inflation: 장애물 주변 비용을 거리에 따라 감쇠, 대표적으로 $c(d)=c_{\max}\,e^{-\alpha(d-r_{\text{inscribed}})}$ 형태
- **inflation 튜닝의 상충** → 반경·감쇠를 키우면 안전 여유 증가, 대신 좁은 통로 통과 실패
- **전역 플래너 vs 로컬 컨트롤러**
  - 전역: 지도 전체 경로, 재계획 주기에 따라 동적 장애물 대응
  - 로컬: 짧은 시간 창에서 속도 명령 최적화, 즉각 회피 담당
- **동적 장애물** → 지나간 장애물 흔적이 costmap에 남거나(clearing 부족) 늦게 반영되면 불필요한 재계획·정지 발생
- **회귀 게이트(regression gate)** → 한 시나리오 개선이 다른 시나리오를 망가뜨리지 않았는지 고정 시나리오 묶음으로 확인 후 채택
  - 단일 실행 결과는 운에 좌우 → 반복 측정·지표 비교 필요(45강)
