# [38강. Localization·상태 추정 (AMCL·Particle Filter·Kalman/EKF)]
- 모듈: ⑥ SLAM 및 Nav2 자율주행
- 한 줄 요약: "지도 위에서 나는 지금 어디인가"를 **확률 분포(믿음)의 예측→보정 반복**으로 푸는 베이즈 상태 추정의 틀을 잡고, 칼만 필터·EKF·파티클 필터·AMCL을 같은 문법으로 읽기
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** 모든 필터는 **예측(분포 넓어짐) → 보정(분포 좁아짐)** 사이클이라는 공통 구조 설명
- **필수 ②** 칼만 이득 $K$를 **"측정을 얼마나 믿을지의 자동 손잡이"**로 해석
- **필수 ③** 파티클 필터는 EKF와 달리 **다봉 분포(여러 후보)**를 표현 → 전역 추정·납치 문제에 강함
- 심화(선택): 칼만 공식 유도, 베이즈 정리와의 관계, KLD 샘플링 — 행렬 공식 암기 불필요, 기호의 역할만 읽으면 됨
- 인터랙티브 자료: `Lv2/인터랙티브/38_칼만필터_예측과_보정.html` — $Q$·$R$을 바꾸며 $K$의 자동 조절 관찰

## [핵심 개념]
- **직관 — 눈 감고 걷기**
  - "세 걸음 걸었으니 여기쯤" = 예측(모델·오도메트리, 불확실성↑)
  - "문이 왼쪽에 보이네" = 보정(측정, 불확실성↓)
  - 위치를 점이 아니라 **가능성의 안개**로 보면: 이동 시 미끄러짐으로 퍼지고, 관측 시 맞는 곳만 남아 뭉침
  - 긴 복도 한가운데서 앞뒤 구분이 어려운 현상도 같은 틀로 설명
- **베이즈 필터의 공통 뼈대**
  - 예측: $bel^-(x_t)=\int p(x_t\mid x_{t-1},u_t)\,bel(x_{t-1})\,dx_{t-1}$
  - 보정: $bel(x_t)\propto p(z_t\mid x_t)\,bel^-(x_t)$
  - 필터 간 차이는 오직 **분포 표현 방법** — 가우시안 하나(KF) vs 점 구름(파티클)
- **칼만 필터(KF) — 가우시안 믿음(평균 $\mu$, 공분산 $P$)**
  - 예측: $\mu^-=A\mu+Bu,\quad P^-=APA^\mathsf T+Q$ → $Q$를 더함 = "움직였으니 더 불확실"
  - 보정: $K=P^-H^\mathsf T(HP^-H^\mathsf T+R)^{-1}$, $\mu=\mu^-+K(z-H\mu^-)$, $P=(I-KH)P^-$
  - $z-H\mu^-$ = **혁신(innovation)**, 예상과 실제 측정의 차이 → $K$만큼 반영
  - 기호: $\mu$ 추정 평균 [m], $P$ 공분산 [m²], $Q$ 프로세스 노이즈, $R$ 측정 노이즈, $H$ 측정 행렬, $A,B$ 모델 행렬
- **칼만 이득 $K$의 의미**
  - $R$ 작음(좋은 센서) → $K$ 큼 → 측정 쪽으로 크게 끌림
  - $Q$·$P^-$ 작음(모델 확실) → $K$ 작음 → 측정 조금만 반영
  - = 모듈 ① 6강 **EMA의 $\alpha$를 노이즈 통계로 매 스텝 자동 계산**한 것
  - 교안 그림: 등속 물체 추적 — 추정이 측정보다 매끈하고 지연 작음, ±2σ 밴드가 보정마다 좁아지고 예측마다 넓어지는 "숨쉬기", 측정 두절 구간(3~4초)엔 예측만으로 이어가며 밴드 확대 (35강 등속 외삽의 정식판)
- **EKF — 비선형 대응**
  - 로봇 운동 $x'=x+v\cos\theta\,dt$ 등은 비선형 → 현재 추정점에서 **Jacobian으로 선형화** 후 KF 공식 적용 (11강 Jacobian의 세 번째 등장)
  - 대표 실전: `robot_localization`이 휠 오도메트리+IMU 융합 → `/odom` 정제
    - `process_noise_covariance` = $Q$, 센서별 공분산 = $R$ → 잘못 주면 "센서를 안 믿거나 너무 믿는" 추정
  - 한계: **단봉 가우시안**만 표현 → "문 세 개 중 하나 앞" 같은 다봉 믿음 불가, 선형화 오차로 발산 가능
- **파티클 필터 — 샘플 수천 개로 믿음 표현** (파티클 1개 = "여기 있을지도"라는 가설)
  1. 예측: 각 파티클을 오도메트리+노이즈로 이동
  2. 가중치: 파티클 위치에서 예상되는 지도 관측과 실제 스캔 비교 → 가능도 부여
  3. 리샘플링: 가중치 비례 재추출 — 그럴듯한 가설 번식, 나머지 도태
  - 교안 그림: 전역 균일 살포 → 복도 대칭성 때문에 **두 덩어리** → 모퉁이의 비대칭 관측으로 한 덩어리 수렴
  - 다봉 표현 덕분에 **전역 위치 추정·납치 문제** 해결 가능 (EKF는 불가)
- **AMCL(Adaptive Monte Carlo Localization)** = 점유 격자 지도 위 파티클 필터 + 실전 장치 2가지
  - Adaptive(KLD 샘플링): 불확실하면 파티클 증가(수천), 수렴하면 감소(수백) → 계산 절약
  - 리커버리: 가중치가 전반적으로 낮으면(추정이 틀렸다는 신호) 무작위 파티클 재살포 → 재수렴 기회 (35강 상태 머신 SEARCHING과 같은 사상)
- **선택 기준 — KF 계열 vs 파티클**

  | 항목 | KF/EKF | 파티클(AMCL) |
  |---|---|---|
  | 믿음 표현 | 가우시안 한 봉우리 | 임의 분포(다봉 가능) |
  | 계산 | 가벼움(행렬 몇 개) | 파티클 수에 비례 |
  | 전역 추정·납치 | 불가 | 가능 |
  | 대표 용도 | 오도메트리+IMU 융합, 추적 | 지도 위 위치 추정 |
  | 패키지 | `robot_localization` | AMCL |

  - 실전은 보통 **둘 다 — 2층 구조**: EKF가 빠른 주기로 odom 정제, AMCL이 느린 주기로 map 기준 전역 보정 (39강 `map→odom→base_link`)
  - ※ 이 저장소의 41~45강 실습은 2D AMCL 대신 cuVSLAM이 위치 공급(재위치 추정은 42강 `localize_in_map`) → AMCL은 개념·2D 비교 구성으로 이해
- **(심화) 왜 곱셈인가 — 베이즈 정리**
  - 보정식 = $p(x\mid z)=\frac{p(z\mid x)\,p(x)}{p(z)}$: 사전 믿음(예측) × 측정 가능도 = 사후 믿음
  - "문 앞" 가능도 × "현재 근방" 예측 → 곱이 큰 곳 = 두 정보의 교집합
  - 가우시안×가우시안=가우시안 → 칼만 보정식의 정체, 샘플에 가중치 곱 → 파티클 보정의 정체 → **모든 필터는 베이즈 정리의 구현체**

## [용어]
- **믿음(belief)**: 위치에 대한 확률 분포 — 점 추정(값 하나)과 다름
- **예측 단계**: 모델로 이동시키며 불확실성 키우기 — 센서 없이도 진행되나 오래 지속하면 안개가 걷잡을 수 없이 퍼짐
- **보정 단계**: 측정으로 분포 좁히기 — 드리프트를 잡는 유일한 수단, 측정이 나쁘면 오히려 악화
- **공분산 $P$**: 추정된 불확실성의 크기·모양 — 실제 오차와 다름
- **칼만 이득 $K$**: 측정을 믿는 비율 — 사람이 튜닝하는 게인이 아니라 계산되는 값
- **EKF**: 비선형 모델을 선형화해 쓰는 KF — 선형화 오차로 발산 가능
- **파티클 필터**: 샘플로 분포 표현 — 계산량이 파티클 수에 비례
- **리샘플링**: 그럴듯한 가설만 복제 — 너무 자주 하면 다양성 소실(입자 고갈)
- **AMCL**: 지도 위 파티클 필터 실전판 — SLAM 아님, 지도가 이미 있어야 함
- **납치 문제(kidnapped robot)**: 로봇을 갑자기 옮긴 상황 — 초기 위치 오차와 다른, 전역 재수렴 능력의 시험

## [선수 지식·연결]
- 모듈 ① 6강: EMA 필터 $\alpha$ → 칼만 이득의 원형
- 11강: Jacobian(EKF 선형화), 35강: 등속 외삽·SEARCHING 상태(측정 두절·리커버리의 원형)
- 37강: SLAM 개요(지도 만들기) → [L37](../L37_SLAM_원리와_도구_비교/), 39강: 2층 구조(`map→odom→base_link`)와 Loop Closure → [L39](../L39_Mapping_Localization_데이터_흐름과_Loop_Closure/)
- 42강: 저장 지도 위 재위치 추정·납치 상황 복구(실습은 cuVSLAM `localize_in_map`) → [L42](../L42_cuVSLAM_지도_재위치_추정_추적_복구/)
- 43강: Nav2 풀스택 위 위치 공급 → [L43](../L43_Nav2_다중_Waypoint_주행/), 이후 모듈 ⑩ 물체 추적도 같은 필터 문법

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **1차원 칼만 필터**: 상태 [위치, 속도]의 등속 모델 KF로 노이즈 측정 추적 그림 재현 → $R$을 10배 키우고/줄이며 추정이 측정·모델 중 어느 쪽에 붙는지 관찰
2. **측정 두절 실험**: 측정을 2초 끊고 추정과 ±2σ 밴드의 변화, 측정 재개 시 복귀 과정 그리기
3. **미니 파티클 필터**: 1차원 원형 복도(문 3개)에서 파티클 200개로 이동+문 감지 반복 → 다봉→수렴 과정을 애니메이션 프레임으로 저장
4. **(심화)** 실습 3 수렴 후 로봇 "납치" → 리커버리(랜덤 파티클 5% 상시 주입) 유무에 따른 재수렴 비교

## [확인 포인트]
- 예측과 보정 단계에서 분포의 폭은 각각 어떻게 변하며 왜 그런가? (모델 노이즈 주입 vs 측정 정보)
- 칼만 이득을 "자동 EMA"라 부를 수 있는 이유를 $R$과 연결해 설명할 수 있는가? ($R\downarrow\Rightarrow K\uparrow$)
- EKF의 "E"가 하는 일과 그 수학 도구는? (현재 추정점에서의 선형화, Jacobian)
- 대칭 복도에서 파티클 믿음이 두 덩어리가 되는 이유와 EKF가 이를 못 다루는 이유는? (관측이 두 위치에서 같음 / 단봉 가우시안)
- AMCL의 Adaptive와 리커버리는 각각 어떤 문제를 해결하는가? (계산량 / 잘못된 수렴·납치)
