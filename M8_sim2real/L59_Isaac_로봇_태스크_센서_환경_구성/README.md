# [59강. [실습] Isaac 로봇 태스크·센서 환경 구성]
- 모듈: ⑧ Sim2Real 및 가상 물리 시뮬레이션
- 한 줄 요약: 태스크 명세서(관측·행동·성공/실패 조건)를 `ReachTask` 클래스로 코드화하고, 학습 중 훈련 조건과 모의 실물 조건을 동시에 평가하는 배선을 붙임

## [핵심 개념]
- **태스크 = 명세서의 코드화**
  - 관측 공간, 행동 공간, 보상, 종료 조건을 먼저 문서로 정하고 그대로 구현
  - 인터페이스: `reset(env_ids)`, `step(actions)`
- **부분 리셋 `reset(env_ids)`**
  - 병렬 환경은 종료 시점이 제각각 → 끝난 환경의 인덱스만 초기 상태 분포에서 재샘플링
  - 전체 리셋 시 진행 중인 에피소드가 끊김
- **관측 설계 규율**
  - $o=[\theta,\dot\theta,\,p_{obj}-p_{ee}]$: 관절각, 관절속도, 물체 상대 위치
  - 전부 실물 센서(엔코더, 카메라 추정)로 구할 수 있는 값 → 55강 규율
- **행동: 관절 델타 + 클램프**
  - $\theta^{target}_{t}=\theta_t+\text{clip}(a_t,-\Delta_{max},\Delta_{max})$
  - 한 스텝 변화량을 제한해 급격한 명령 방지, 실물 안전성 확보
- **성공·실패 조건**
  - 성공: 손끝-물체 거리 < 2 cm를 0.5 s 유지 (순간 통과가 아닌 유지 조건)
  - 실패: 시간 초과, 관절 한계 도달
- **상주 평가(train vs proxy)**
  - `train_sr`: 훈련 분포에서의 성공률
  - `proxy_sr`: 모의 실물 환경(57강 실습 1에서 만든 환경)에서의 성공률
  - 두 곡선의 차이 = Sim2Real gap의 조기 지표 → 과적합(훈련 조건 특화) 감지

## [파일별 내용]
- `01_태스크_구현_명세서의_코드화_의사코드.txt` — `ReachTask` 인터페이스 의사코드
  - `reset(self, env_ids) -> obs`: 지정 환경만 초기화
  - `step(self, actions) -> obs, reward, done, info`
  - 주석으로 관측·행동·성공/실패 명세 기술
  - 함수 본문 없음(시그니처와 명세만), 보상 함수 구체식은 발췌에 없음
- `02_기준_학습_성립_의_증명.ipynb` — 학습 루프 안에 삽입되는 평가 조각
  - `if step % EVAL_EVERY == 0`: 일정 주기마다 평가
  - `eval_on(env_train)` → `train_sr`, `eval_on(env_proxy)` → `proxy_sr` 로깅
  - 빠진 맥락: 학습 루프 본체, `EVAL_EVERY`, `eval_on`, `log` 정의, 두 환경 생성 코드
  - "성립의 증명": 기준(랜덤화 없는) 학습이 수렴함을 먼저 보여 이후 60강 DR 효과를 비교할 기준선 확보
