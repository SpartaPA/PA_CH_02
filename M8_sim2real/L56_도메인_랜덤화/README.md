# [56강. 도메인 랜덤화 (Texture·Lighting·Mass·Friction)]
- 모듈: ⑧ Sim2Real 및 가상 물리 시뮬레이션
- 한 줄 요약: "현실과 똑같은 시뮬 하나" 대신 "현실을 포함할 만큼 다양한 시뮬 수천 개"로 학습해 **실물을 훈련 분포의 내부점(ID)으로** 만드는 Sim2Real의 핵심 처방과, 범위 설계의 트레이드오프를 이해
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** DR의 핵심 논리 — **현실을 훈련 분포 안에 넣는다** — 를 그림으로 설명
- **필수 ②** 무엇을 흔들 수 있는지(물리 파라미터·시각 요소) 예시 제시
- **필수 ③** 범위가 **좁으면 못 덮고 넓으면 못 배운다**는 트레이드오프 설명
- 심화(선택): 자동 커리큘럼(ADR), 랜덤화 축의 절제 실험 → 60강에서 직접 측정

## [핵심 개념]
- **발상의 전환**
  - 정밀 일치는 막다른 길: 실물 마찰은 위치·먼지 상태마다 다름
  - 에피소드마다 질량·마찰·조명·텍스처를 흔들면 정책이 특정 값이 아닌 **변화 자체에 강건한 전략** 학습
  - 25강 데이터 증강·51강 노이즈 주입과 같은 계열 사상의 완성형 (OpenAI 큐브 조작 손 등 성공 사례의 공통 재료)
- **핵심 논리 — 현실을 분포 안에 가두기**
  - 파라미터 공간(마찰×질량)에서 단일 시뮬(점)과 현실(별)의 어긋남 = gap
  - 랜덤화 분포(구름)가 현실을 덮으면 실물은 OOD가 아니라 **ID** (51강 이탈 실험의 언어)
  - $\pi^*=\arg\max_\pi\,\mathbb E_{\xi\sim p(\xi)}\left[\text{성능}(\pi,\text{환경}(\xi))\right]$
    - $\xi$: 랜덤화 파라미터(마찰 계수, 질량 [kg], 조명, 지연 [ms] 등), $p(\xi)$: 그 분포
    - 단일 환경 최고 성능이 아닌 **환경들의 평균 성능** 최대화 → "어떤 환경일지 모르는 채로 잘하는 정책"
  - 정책은 $\xi$를 모르므로 보수적·적응적 전략 선택(더 단단히 쥐기, 여유 있는 궤적)
  - 대가: 평균 성능의 소폭 희생 — 강건함은 공짜가 아님
- **무엇을 흔드는가 ① 시각 랜덤화** (렌더 기반 관측을 쓸 때)

  | 항목 | 범위 예 | 막는 것 |
  |---|---|---|
  | 텍스처·색 | 물체·바닥·배경을 무작위 재질로 | "특정 색·무늬 = 물체" 지름길 (19강 색 검출 취약점) |
  | 조명 | 방향·세기·색온도·그림자 | 조명 과적합 (16강 HSV 문제) |
  | 카메라 | 포즈 지터·FOV·노이즈·블러 | 장착 오차·센서 차이 (20강) |
  | 방해물 | 무관한 물체 배치 | 배경 의존 |

  - 역설적 발견: 텍스처를 비현실적으로 심하게 흔들면 색·질감을 못 믿게 되어 **형태·기하**에 의존 → "현실적 렌더링"보다 "비현실적일 만큼 다양한 렌더링"이 이식에 유리할 수 있음
- **무엇을 흔드는가 ② 물리 랜덤화**

  | 항목 | 범위 예 | 현실의 무엇 |
  |---|---|---|
  | 질량·관성 | 공칭 ±20% | 제조 편차, 적재물 |
  | 마찰 계수 | 0.4~1.2 | 표면 상태, 마모 |
  | 모터 게인·토크 한계 | ±15% | 개체차, 전압 변동(모듈 ①) |
  | 행동 지연 | 0~40 ms | 통신·처리 지연 (21강·34강) |
  | 관측 노이즈 | 센서 스펙 기반 | 6강·31강 실측 노이즈 |
  | 초기 상태 | 넓게 | 배치 다양성 (46강) |

  - **행동 지연은 필수 항목**: 시뮬 기본값이 지연 0이라 잊기 쉽지만 실물 이식 실패의 단골 원인(34강 지연 예산)
- **범위 설계 — 새로운 하이퍼파라미터**
  - 너무 좁음: 현실이 분포 밖에 남아 gap 잔존
  - 너무 넓음: 학습 붕괴 또는 지나치게 보수적(느린) 정책
  - 랜덤화 폭에 대한 두 곡선: 시뮬 성능은 단조 하락, 실물 성능은 **산 모양**(적정 폭에서 최대)
  - 적정점의 근거 = **실물 파라미터의 불확실성 추정** (61강에서 실측)
- **실무 절차 (60강에서 수행)**
  1. 파라미터별 공칭값·불확실성 추정(스펙시트·실측·상식) → 초기 범위
  2. 좁은 범위로 학습 성립 확인 → **한 축씩** 넓히며 시뮬 성능 하락 감시 (44강 단일 변경 원칙)
  3. 학습이 버거우면 커리큘럼(성공률 연동 폭 확대)
  4. 최종 평가는 **범위 밖 파라미터의 시뮬**(모의 실물)로 — 53강 스트레스 시험 재사용
- **커리큘럼·ADR**
  - 좁게 시작 → 성공률이 문턱을 넘으면 폭 확대하는 계단 → 넓은 범위 학습 붕괴 회피
- **(심화) 랜덤화를 넘어 — "견디기(DR) ↔ 알아내기(ID)" 스펙트럼**
  - 이력 조건부 정책: 최근 관측-행동 이력을 입력 → 지연·질량이 이력에 드러나 암묵적 적응
  - RMA(Rapid Motor Adaptation): 시뮬에서 $\xi$ 참값으로 인코더 학습 → 실물에서는 이력으로 $\xi$ 잠재 추정 (사족보행 이식의 돌파구)
  - 명시적 System ID(58강): 실측으로 $\xi$를 좁혀 랜덤화 범위 자체 축소 → 실무는 보통 혼합

## [용어]
- **도메인 랜덤화(DR)**: 시뮬 조건을 무작위로 흔들며 학습 — 데이터 증강과 비슷하나 환경 자체를 흔듦
- **ID / OOD**: 훈련에서 겪어 본 / 겪어 본 적 없는 분포 — 47강 공변량 이동과 같은 언어
- **물리 랜덤화 vs 시각 랜덤화**: 동역학 갭(마찰·질량·지연) 대응 vs 인지 갭(조명·텍스처·카메라) 대응, 렌더 품질 향상과는 다른 접근
- **범위(range) 설계**: 얼마나 넓게 흔들지 — 넓다고 좋은 것이 아님
- **강건성 vs 성능**: 어디서나 무난함 vs 한 곳에서 최고, 동시 최대화 불가
- **ADR(자동 커리큘럼)**: 잘하면 범위를 넓혀 가기 — 고정 범위 DR과 대비
- **절제 실험(ablation)**: 축을 하나씩 빼며 기여 확인 — 전체 성능만으론 어느 축이 일했는지 모름

## [선수 지식·연결]
- 25강 이미지 증강·51강 노이즈 주입/OOD 이탈 실험·53강 스트레스 시험이 DR의 전신
- 34강 지연 예산: 행동 지연 랜덤화의 근거
- 55강: 병렬 환경마다 서로 다른 $\xi$ → 한 배치가 곧 여러 도메인 → [L55](../L55_Isaac_Sim_Isaac_Lab_태스크_구성/)
- 57강: gap의 계열별 해부, 지연 주입 시험으로 "지연 랜덤화 필수"의 실험적 확인 → [L57](../L57_Sim_to_Real_Gap_원인_분석/)
- 58강: System ID 잔차 = DR 범위의 근거, "맞출 수 있는 건 맞추고 못 맞추는 건 흔든다" → [L58](../L58_보정_전략과_평가_지표/)
- 60강: 리셋 시점 랜덤화 `DomainRandomizer`·ADR 구현, 범위별 성능 측정 → [L60](../L60_도메인_랜덤화_학습_환경_구축/)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **랜덤화 설계서**: 60강 2링크 도달 태스크용 설정표 — 물리 5항목 + 관측 2항목의 (공칭값, 불확실성 근거, 분포, 범위), "행동 지연" 필수
2. **증강과의 비교표**: 25강 이미지 증강·51강 노이즈 주입·DR을 (무엇을 흔드나 / 어느 단계 / 막는 실패)로 비교 → 한 가족임을 정리
3. **미니 DR 실험**: 모듈 ⑦ 2링크 환경에서 링크 길이 고정 vs ±10% 랜덤화로 BC(51강 코드) 학습 → ±15% 시험 환경 성공률 비교
4. **(심화)** 실습 3에 커리큘럼(성공률 80% 초과 시 폭 +5%p) 추가 → 처음부터 넓게 학습한 경우와 최종 성능·안정성 비교

## [확인 포인트]
- DR의 핵심 논리를 ID/OOD 언어로 한 문장으로 말할 수 있는가 (실물을 분포 안으로)
- 텍스처를 비현실적으로 흔들면 정책이 무엇에 의존하고 왜 이식에 유리한가? (형태·기하)
- 물리 랜덤화에서 행동 지연을 빠뜨리면 안 되는 이유는? (시뮬 기본 지연 0, 34강)
- 범위가 너무 넓을 때의 두 가지 문제는? (학습 붕괴, 과도하게 보수적인 정책)
- ADR이 넓은 범위 학습 붕괴를 피하는 방식은? (좁게 시작, 성공률 연동 확대)
