# [57강. Sim-to-Real Gap 원인 분석]
- 모듈: ⑧ Sim2Real 및 가상 물리 시뮬레이션
- 한 줄 요약: "실물에서 안 된다"를 **시각·물리·시스템** 세 계열로 분해하고, 원인을 분리해서 재는 진단 실험(관측 교차·개루프 재생·지연 주입)으로 "어느 계열의 gap이 얼마"인지 정량화
- ※ 교안에 코드 블록이 없는 이론 강의 → 이 폴더는 요약만 담음

## [필수 이해 기준 (교안 기준)]
- **필수 ①** Sim2Real gap을 계열별(인지·동역학·환경/시스템)로 나눠 설명
- **필수 ②** 원인 분리 진단 실험(참값 관측 우회·개루프 재생)의 **설계 의도** 설명
- **필수 ③** gap을 숫자로 정량화해 **리포트로 남김**
- 심화(선택): 오차 파형에서 원인 추정(마찰·백래시·지연의 서명)

## [핵심 개념]
- **진단의 태도**
  - 시뮬 95% → 실물 40%는 통과 의례 — 파라미터를 마구 돌리지 말고 의사처럼 진단
  - 분해 → 원인별 크기 측정 → 큰 것부터 처방 (34강 "떨림 3단 분리", 53강 스트레스 축의 진화형)
- **Gap의 해부학 — 루프에 끼어드는 세 자리**
  - 루프: 관측 → 정책 → 행동 → 물리 → 관측…

  | 계열 | 대표 원인 | 전형 증상 |
  |---|---|---|
  | 시각/관측 | 질감·조명 차이, 센서 노이즈·화이트밸런스 | 처음부터 엉뚱한 방향 (인지 단계 붕괴) |
  | 물리/동역학 | 마찰·질량 오차, 접촉 모델 근사, 케이블 장력 | 접근은 정상, 접촉 순간 실패 (미끄러짐·힘 과소/과대) |
  | 시스템 | 지연(추론+통신), 주기 지터, 모터 데드존(5강)·백래시 | 진동·오버슈트 (34강의 그 얼굴) |

  - 접촉 물리는 특히 악명: 시뮬 접촉은 수치 근사(연성 접촉·이산 시간) → 파라미터를 맞춰도 **정성적으로** 다를 수 있음 → 조작 과제 gap > 이동 과제 gap
  - 53강 "물리 변화 취약 곡선" = 이 gap의 사전 예보
- **실험 A — 관측 교차 시험 (시각 gap 분리)**
  - 시뮬 정책 + 실물 관측 재생(실물 이미지 입력) → 행동이 무너지면 시각 gap
  - 실물 상태를 **참값 관측으로 우회**(마커·모캡으로 저차원 상태 공급) → 성공하면 병은 시각에 있음이 확정
- **실험 B — 개루프 궤적 재생 (동역학 gap 정량화)**
  - **같은 행동 시퀀스** $a_{1:T}$를 시뮬·실물에 재생해 상태 궤적 비교 → 정책을 배제했으므로 순수 동역학 차이만 남음
  - $\text{gap}_{dyn}=\frac1T\sum_t\|s^{real}_t-s^{sim}_t\|$ ($s_t$: 관절각 등 [rad], $T$: 스텝 수)
  - **오차의 "모양"이 원인의 지문** (23강 "오차 모양으로 버그 진단"의 물리판)
    - 가속 구간에서 벌어짐 → 관성
    - 방향 반전 구간 → 백래시·데드존
    - 정지 직전 → 정지 마찰
  - 62강 System ID에서 이 오차를 목적 함수로 승격 → 진단 도구가 보정 도구가 됨
- **실험 C — 지연 주입 시험 (시스템 gap)**
  - 시뮬에 실측 지연(34강 방법)을 주입 → 실물과 비슷해지면 시스템 gap이 주범
  - 56강 "지연 랜덤화 필수"의 실험적 확인
- **정량화 리포트 — gap의 회계장부**
  - 시각: 교차 시험의 성능 낙폭 / 동역학: 재생 오차 RMS + 구간별 태그 / 시스템: 실측 지연 분포 + 주입 시험 결과
  - 계열별 **추정 기여도** 파이 → 58강 처방의 입력
  - 기여도 큰 계열부터 계열에 맞는 처방: 시각 → 시각 DR·실데이터 미세조정 / 동역학 → System ID·물리 DR / 시스템 → 지연 모델링·제어 주기 정비
- **진단의 규율 (기존 규율 재사용)**
  - 한 번에 하나만 변경(44강), 반복해 분포로 보고(45강), 실패 bag/로그로 부검(45강)
  - 새로운 것은 "무엇을 재는가"뿐
- **(심화) 폐루프는 gap을 숨긴다**
  - 개루프 재생에서 크게 벌어져도 피드백 제어로는 곧잘 추종 → 피드백이 모델 오차를 흡수(1강 폐루프의 존재 이유)
  - 함의 ①: "학습 정책(목표) + 저수준 피드백(PID 서보)" 구조가 gap에 강함 → 행동 공간을 토크 직접보다 "목표+서보"로 두는 실무 선호
  - 함의 ②: 진단은 반드시 개루프로 — **"운용은 폐루프, 진단은 개루프"**

## [용어]
- **Sim2Real gap**: 시뮬과 실물의 성능 차이 — 단일 원인이 아닌 여러 계열의 합
- **인지 갭**: 시뮬 이미지와 실사의 차이 — 동역학 갭과 처방이 다름
- **동역학 갭**: 같은 명령에 다른 움직임 — 제어 게인 문제와 구분 필요
- **환경 갭**: 배치·조명·마찰면 등 상황 차이 — 실험 조건 기록으로 상당 부분 해결
- **개루프 재생**: 같은 명령을 양쪽에 흘려보내기 — 정책 평가와 목적이 다른 원인 분리 실험
- **참값 관측 우회**: 마커·모캡으로 상태 직접 공급 — 실전 구성이 아닌 진단용
- **서명(signature)**: 오차의 특징적인 모양 — 오차 크기만으론 원인 불명
- **정량화 리포트**: gap을 숫자로 정리한 문서 — 보정 우선순위 결정, 인상평과 다름

## [선수 지식·연결]
- 1강 폐루프, 5강 데드존, 34강 지연·떨림 분리, 44·45강 단일 변경·부검 규율, 53강 스트레스 평가기
- 56강: DR 카탈로그, 행동 지연 랜덤화 → [L56](../L56_도메인_랜덤화/)
- 58강: 회계장부를 입력으로 System ID·Fine-tuning 처방 선택 → [L58](../L58_보정_전략과_평가_지표/)
- 61강: 실물(대리) 배포·쌍대 평가 → [L61](../L61_학습_정책_실물_배포_성능_검증/)
- 62강: 재생 오차를 목적 함수로 한 System ID(CMA-ES) → [L62](../L62_실패_케이스_분석_보정_전략_적용/)

## [교안의 실습 과제]
- 코드 블록은 없지만 교안이 직접 해 보라고 제시한 과제
1. **모의 gap 만들기**: 모듈 ⑦ 2링크 시뮬 복제 → "모의 실물"(링크 길이 +7%, 마찰 추가, 행동 지연 30 ms, 관측 노이즈) — 61강까지 쓸 실물 대리
2. **개루프 재생 진단**: 같은 행동 시퀀스를 원본·모의 실물에 재생 → 상태 오차 곡선 + 구간별 원인 태깅(가속/반전/정지)
3. **분리 시험**: 교란을 하나씩 켜고 끄며(지연만/마찰만/길이만) 53강 평가기로 성공률 측정 → 실제 데이터로 기여도 파이 작성
4. **(심화)** 폐루프 은폐 확인: 행동 재생을 "목표 재생 + PID 추종"으로 바꿔 궤적 오차 감소량 비교

## [확인 포인트]
- gap의 세 계열과 각 전형 증상을 한 줄씩 말할 수 있는가
- "접근은 정상인데 잡는 순간 실패"의 유력한 병명은? (물리 gap — 접촉 모델 근사)
- 참값 관측 우회 시 성공한다는 것의 의미는? (병이 시각/인지 쪽)
- 동역학 gap을 개루프 재생으로 재야 하는 이유는? (피드백이 오차를 흡수해 숨김)
- 방향 반전 구간에서만 오차가 튀는 패턴의 원인 후보 두 가지는? (백래시, 데드존)
